# 合同诈骗罪民刑切割与非法占有目的审查方法论

## 一、适用场景

适用于合同诈骗罪、诈骗罪、骗取贷款罪等财产犯罪中，控方将经营亏损、合同违约、资金周转、以新还旧、关联公司资金调配、客户损失等事实刑事化评价的案件。

尤其适用于：

- 审查起诉阶段的不起诉或补充法律意见。
- 一次退查后，控方仍以损失结果、审计报告、口供推定犯罪。
- 交易模式复杂，涉及投资、预付款、货物交付、对冲交易、账期、关联公司资金往来。

## 二、核心原则

合同诈骗辩护不能只说“这是民事纠纷”，而要回答四个问题：

```text
交易模式是什么
→ 客户损失是否属于交易风险实现
→ 行为人签约履约时是否具有非法占有目的
→ 控方证据能否排除经营亏损、民事违约、合同权利处分等合理解释
```

稳定判断：

- 损失结果不能反推合同诈骗。
- 经营亏损不能反推非法占有目的。
- 资金周转不能当然等同于以新还旧。
- 合同权利处分不能轻易被刑事否定。
- 民法允许或容忍的经营行为，原则上应排斥犯罪评价，除非控方能证明诈骗构成要件。

## 三、第一步：还原交易模式

合同诈骗案件先不要急于争论罪名，应先把交易结构做成表。

| 审查项 | 具体问题 |
| --- | --- |
| 合同主体 | 谁与谁签约，是否真实存在，是否冒名或虚构主体 |
| 交易标的 | 货物、服务、投资款、预付款、保证金、定金分别是什么 |
| 交易流程 | 下单、付款、交货、结算、退款、延期、对冲或资金调配如何发生 |
| 风险分配 | 价格波动、库存、资金占用、账期风险由谁承担 |
| 客户认知 | 客户是否多次交易，是否熟悉交易方式，是否曾经获利 |
| 禁止约定 | 合同是否禁止特定资金用途、货物处分或第三方交易 |
| 履约记录 | 是否存在部分履行、持续履行、真实经营、真实结算 |

输出结论时，应把案涉行为放回交易模式中评价，而不是只看最终未兑付结果。

## 四、第二步：拆合同诈骗的行为属性

《刑法》第二百二十四条列举的五类行为，要逐项对应，不得用概括性语言替代构成要件。

| 法定行为方式 | 审查重点 | 常见抗辩 |
| --- | --- | --- |
| 虚构单位或冒用他人名义 | 主体是否真实、是否有经营资格 | 公司真实成立、合法存续、持续经营 |
| 虚假票据或产权证明担保 | 担保材料是否虚假，是否影响相对人决策 | 无此类担保或不影响合同目的 |
| 无实际履行能力诱骗继续履行 | 签约时是否明知无能力，是否仅小额履行诱骗 | 有履约记录、经营能力、资金投入 |
| 收受财物后逃匿 | 是否携款潜逃、失联、拒绝承担债务 | 持续经营、沟通、结算、未逃避债务 |
| 其他方法骗取财物 | 欺骗内容、错误认识、处分财产、因果关系 | 客户明知交易模式，损失来自经营风险 |

## 五、第三步：审查非法占有目的

合同诈骗罪要求签约、履约时具有非法占有目的。不能用事后亏损、资不抵债、未兑付结果倒推主观目的。

### 1. 控方常用推定

| 控方推定 | 反制问题 |
| --- | --- |
| 后来无法兑付，所以从一开始就是骗 | 签约履约时是否已有不能履行且不准备履行的证据 |
| 账上余额不足，所以资不抵债 | 债务是否到期，是否存在账期和持续经营收入 |
| 新款兑付旧款，所以以新还旧 | 是否属于正常经营资金周转，是否有真实业务基础 |
| 关联公司资金往来，所以拆东墙补西墙 | 是否属于关联经营、资金拆借、统一调配 |
| 股东分配财产，所以导致无法履行 | 分配时间、金额、对象、去向、因果关系是否查清 |

### 2. 辩方反证

| 反证事实 | 证明目的 |
| --- | --- |
| 持续经营较长时间 | 不是一开始即以骗财为目的 |
| 多次真实履约或部分履约 | 存在履行合同意愿和行为 |
| 客户曾经盈利 | 交易模式客观上可能实现合同目的 |
| 行为人或亲属投入资金 | 有盈利预期，反证非法占有目的 |
| 未逃匿、未失联、未挥霍 | 不符合典型诈骗外观 |
| 有第三方交易、采购、对冲记录 | 证明经营行为真实存在 |

## 六、第四步：民刑切割与法秩序统一性

合同诈骗案件中的民刑切割，不能停留在“这是民事纠纷”。应当证明民事权利义务如何产生，以及刑法为什么不能越过民法直接定罪。

审查顺序：

```text
合同是否真实
→ 权利义务是否存在
→ 行为是否属于合同权利处分或履约经营行为
→ 客户是否对风险有认知或预期
→ 损失是否属于交易风险或违约后果
→ 是否仍可通过民事途径主张权利
```

稳定表达：

- 刑事司法不能无视民法的态度。
- 存在合同权利义务前提下，权利处分具有履约性质。
- 民法允许的合同权利处分行为，原则上排斥犯罪评价。
- 刑法不能仅因处罚必要性而取代民法的财产分配机制。

## 七、第五步：犯罪数额审查

合同诈骗罪属于数额犯，必须把不同金额拆开。

| 金额类型 | 是否当然等于诈骗金额 | 审查重点 |
| --- | --- | --- |
| 客户实际交付金额 | 否 | 是否全部基于受骗交付 |
| 合同标的金额 | 否 | 是否已经履行、结算、抵扣 |
| 报案损失金额 | 否 | 是否经完整审计，是否扣除既往盈利 |
| 未兑现金额 | 否 | 是否属于到期债务，是否存在盈亏计算 |
| 行为人非法占有金额 | 需要证明 | 谁最终占有，何时占有，以何名义占有 |

审查要求：

- 区分货款两清交易和预付款、付款不提货、投资性交易。
- 区分客户总投入、总回款、净损失和未到期债权。
- 统计长期交易关系中的全部盈亏，不能只截取最后亏损段。
- 微信、支付宝、银行卡、现金、实物交付应一并核算。

## 八、第六步：审计报告质证

审计报告在财产犯罪中常被当作定罪核心，但必须拆证明基础。

| 审查维度 | 追问 |
| --- | --- |
| 资料完整性 | 财务账套、出入库单据、库存记录、银行流水、微信支付宝数据是否完整 |
| 统计口径 | 是否只统计报案人员，是否漏掉长期盈亏和既往盈利 |
| 时间节点 | 资不抵债、以新还旧的起算点如何确定 |
| 债务期限 | 是否把未到期债务当成即时清偿义务 |
| 因果关系 | 某项分配、支出是否真实导致无法兑付 |
| 证据循环 | 审计报告是否引用口供，口供讯问是否又引用审计结论 |

常用表达：

- 审计资料不完整，据此作出的审计结论准确性存疑。
- 以账面余额不足以覆盖尚未提取金额，直接认定资不抵债，忽略了履行期限和支付账期。
- 以报案损失金额直接确定诈骗金额，既无事实根据，也无法律依据。
- 审计报告与讯问笔录相互援引，存在证据循环。

## 九、文书输出结构

```text
一、案涉行为不具备合同诈骗行为属性和法益侵害性
（一）交易相对人可合理预见案涉交易风险
（二）损失结果不能决定合同诈骗成立

二、刑事司法不能无视民法合同权利处分
（一）正常经营、资金调配不当然等于诈骗
（二）刑法判断应顾及民法立场
（三）合同权利处分排斥犯罪评价

三、起诉意见书缺乏证据证明
（一）民事先决问题未查清
（二）犯罪数额认定不清
（三）关键事实缺乏明确性
（四）审计报告依据不足

四、有证据足以推翻非法占有目的
（一）存在真实履约和经营行为
（二）行为人自投资金或亲属投入资金
（三）经营不善属于风险或过失，不是合同诈骗直接故意
```

## 十、进入 skill 的稳定规则

1. 用户输入合同诈骗、经营亏损、客户损失、投资兑付、以新还旧、审计报告、非法占有目的等关键词时，应优先调用本方法。
2. 先生成交易模式表，再生成构成要件拆解表。
3. 对非法占有目的，必须同时列出控方推定和辩方反证。
4. 对犯罪数额，必须区分交付金额、报案损失、净损失、未兑现金额、非法占有金额。
5. 对审计报告，必须审查资料完整性、统计口径、时间节点、债务期限和证据循环。
6. 文书表达应避免空泛说“民事纠纷”，应写成“合同权利处分、交易风险实现、法秩序统一性、刑法谦抑性”。
