# 羁押必要性审查与取保候审变更方法论

## 一、适用场景

适用于审查起诉、一审审理或长期羁押期间，辩护人以事实已查清、证据已固定、可能判处缓刑、认罪退赔和无社会危险性为由，申请释放或变更强制措施的案件。

## 二、核心判断公式

```text
实体案件可能刑期
→ 关键证据是否已固定
→ 是否仍有串供、毁证、逃跑或继续危害社会风险
→ 取保候审能否保障诉讼
→ 继续羁押是否仍有必要
```

羁押必要性不是重新审理无罪问题，但实体金额和罪名争议会直接影响可能刑期、社会危险性和羁押必要性。

## 三、第一步：先做实体案件轻重预估

至少列出：

- 可能排除或扣减的犯罪金额；
- 可能成立的罪名和不成立的备选罪名；
- 自首、坦白、认罪认罚、退赃退赔、谅解等从宽情节；
- 是否属于初犯、偶犯、从犯；
- 可能刑期是否达到缓刑或一年以下的范围。

## 四、第二步：证据固定情况表

| 证据类型 | 是否已固定 | 是否仍需调取 | 是否存在灭失风险 |
| --- | --- | --- | --- |
| 合同、账务明细 |  |  |  |
| 银行流水、微信记录 |  |  |  |
| 证人证言、被害人陈述 |  |  |  |
| 电子数据、后台记录 |  |  |  |
| 鉴定、审计和价格认定 |  |  |  |

当主要证据已经在卷、案件进入审查起诉、被告人身份固定且无现实接触证据风险时，应重点论证继续羁押的必要性下降。

## 五、第三步：社会危险性逐项审查

不要只写“没有社会危险性”，应逐项回答：

- 是否有逃跑、隐匿身份或无固定住所风险；
- 是否可能串供、毁灭、伪造或转移证据；
- 是否可能继续实施同类犯罪；
- 是否可能对被害人、证人实施报复或干扰；
- 取保候审的保证人、保证金、居住地和联系方式是否明确；
- 是否愿意配合调查、按时到案和遵守取保规定。

## 六、第四步：把实体金额表转化为羁押理由

项目化金额表不仅服务无罪辩护，也服务羁押审查：

```text
总额下降
→ 可能刑期下降
→ 主观恶性和实际危害评价下降
→ 缓刑可能性上升
→ 继续羁押必要性下降
```

但必须明确：金额争议和羁押必要性是不同问题，不能仅凭提出无罪意见就当然要求取保。

## 七、第五步：文书双线结构

```text
第一部分：实体法律意见和金额逐笔拆分
第二部分：自首、认罪认罚、退赔和可能刑期
第三部分：家庭抚养、工作和社会影响
第四部分：事实已查清、证据已固定、无现实羁押风险
第五部分：请求释放或变更为取保候审
```

## 八、进入 skill 的稳定规则

1. 看到“羁押必要性审查、变更强制措施、取保候审、证据已固定、可能缓刑”等关键词时，自动建立羁押必要性四栏表。
2. 先核算可能刑期和案件实体轻重，再论证社会危险性。
3. 必须区分证据固定、无罪争议、退赔悔罪和家庭因素各自的证明作用。
4. 取保请求应提出具体保障措施，不能只写家庭困难或社会和谐。
5. 法律意见、量刑意见和羁押申请可以合并，但必须分章节、分证明目的、分请求。

## 九、公安侦查阶段取保候审申请的专门结构

公安机关侦查阶段的取保申请，文书目标是让承办机关同时看到“案件可以不按重罪羁押”和“即使继续核查也不需要羁押”两条路径。推荐采用主位、备位双线：

```text
主位：罪名或金额不成立，属于民事争议或存在重大证据疑问
备位：即使仍需继续侦查，证据已可固定、无现实社会危险性，可以取保
```

具体结构：

1. **先拆款项，再写罪名**：对运营费、推广费、押金、转委托成本、介绍费、退款和已履行部分逐项定性，禁止将全部收款直接等同于诈骗金额。
2. **再做四节点时间轴**：财产交付前的认识和承诺、收款后的履约、争议发生、争议后的伪造或补签文件以及退款还款方案必须分开评价。
3. **把非法占有目的写成综合判断**：实际履约、转委托、业务支出、部分成果、还款计划、退款方案和未逃匿行为共同作为反证，但不能用“有资产”或“愿意还款”单独替代主观故意审查。
4. **实体结论后立即转入羁押必要性**：说明主要证据已经固定、嫌疑人身份明确、没有串供毁证和继续犯罪风险，并提出保证人、保证金、居住地址、联系方式及按时到案等具体保障措施。
5. **到案情节单独核验**：被害人通知到场、带到公安机关或现场抓获，不当然等于自动投案或自首；需核查公安机关是否已掌握犯罪事实、是否已确定嫌疑人、到场是否受控制以及供述是否及时稳定。
6. **家庭理由放在末位**：婴幼儿抚养、家庭收入来源和企业经营影响只能作为社会效果的辅助论据，不能替代罪名、证据和社会危险性论证。

公安阶段取保申请的请求应具体落到“依法变更强制措施为取保候审”，同时避免把“被害人没有实际损失”“有能力偿还”等存在争议的事实写成唯一结论，防止削弱整份申请的可信度。

## 十、取保申请的证据附件清单

对运营推广类诈骗案件，建议随申请书建立以下附件索引：

| 证明事项 | 优先附件 |
| --- | --- |
| 合同和委托基础 | 合作合同、补充约定、聊天记录、收款说明 |
| 实际履约 | 平台后台、团餐核销、推广记录、转委托合同和转账 |
| 金额排除 | 还款计划、退款流水、业务成本、押金用途、第三方分成记录 |
| 主观目的 | 争议后的协商记录、退款或诉讼方案、未逃匿和财产状况材料 |
| 取保保障 | 保证人材料、居住证明、联系方式、遵守取保规定承诺 |
| 家庭因素 | 亲属关系、出生证明、收入和抚养负担材料 |

附件不宜只堆材料，应在正文中注明每份材料证明的具体事实及其对应的罪名要件或取保条件。
