# 犯罪数额核算方法论

## 一、用途

本文件用于沉淀老师在侵财类刑事案件中核算犯罪数额、被害单位损失、经营收益损失、退赔金额的方法。重点适用于职务侵占、盗窃、抢劫、强迫交易、诈骗、拒不返还经营收益、物业收益被转移等案件。

## 二、总原则

犯罪数额核算不能只看行为人实际获利、低价销赃价格或账面收款金额，而应围绕被害单位实际损失、财产市场价值、收益控制权丧失和可客观验证的市场标准展开。

核心判断：

```text
谁的财产/收益被控制
→ 什么时候脱离控制
→ 脱离控制的范围是多少
→ 应按什么客观标准折算
→ 有哪些证据能支撑每个参数
```

## 三、基础工作流

```text
确定被害主体
→ 确定财产/收益类型
→ 确定行为阶段和起止时间
→ 确定权属和控制关系
→ 确定面积、数量、单价、期间等参数
→ 选择核算标准
→ 分项计算
→ 分层汇总
→ 做数值一致性复核
→ 输出证据清单和核算说明
```

## 四、核算层级

### 1. 主体层

- 被害单位是谁？
- 是否存在多个被害单位？
- 是否有自有财产、托管财产、受托管理财产、共有财产？
- 行为人是否通过关联公司、个人账户、第三方主体转移收益？

### 2. 阶段层

按关键法律行为或控制权变化切分阶段：

- 签订委托协议
- 签订委托管理协议
- 变更收款账户
- 实际接管物业
- 解除或终止合同
- 刑事立案、查封、冻结、接管
- 行为实际停止

### 3. 权属层

每一项财产或收益都应标注自有、托管、受托管理、增建/改建、公共面积、停车场、住宅/商铺/办公/仓库/宿舍、待查权属等属性。

### 4. 标准层

| 财产/收益类型 | 可用标准 |
| --- | --- |
| 机器设备、存货、车辆 | 市场价、鉴定价、评估价、实际购买价、市价折余法 |
| 房产、商铺、住宅 | 市场价、评估价、政府指导价 |
| 占有使用收益 | 政府指导租金、市场租金、同类租赁合同 |
| 停车场收益 | 车位数 × 月收费标准 × 期间 |
| 股权、有价证券 | 面值、市场价、评估价、实际交易价中的合理标准 |
| 经营收益 | 实际流水、市场租金、政府指导价、审计报告 |

### 5. 参数层

常用参数包括数量、面积、单价、月数、起算日、截止日、已付款、已返还、已扣除成本、残值、利息或孳息。

### 6. 汇总层

推荐汇总顺序：

```text
单项金额
→ 同一使用人/同一物业小计
→ 同一类型小计
→ 同一阶段小计
→ 全案总额
```

## 五、经营收益型犯罪数额公式

### 1. 租金收益

```text
犯罪数额 = 面积 × 单位租金标准 × 月数
```

面积可以是房产证面积、实际使用面积、承租面积、增建/改建面积。选择实际使用面积时，必须说明理由并提供证据。

### 2. 停车场收益

```text
犯罪数额 = 车位数量 × 每车位月收费标准 × 月数
```

### 3. 分年度指导价

若政府指导价跨年度变化：

```text
犯罪数额 = 第一期间面积×旧标准×月数 + 第二期间面积×新标准×月数
```

## 六、类案规则

### 1. 市场价/评估价优先

侵财类数额犯中，犯罪数额通常应以被侵害财物的市场价、鉴定价、评估价或被害单位实际损失计算，而不是以行为人低价销赃所得计算。

### 2. 低价交易价不能反向压低犯罪数额

被告人低价处分赃物、关联交易、虚假交易、折价转让，不能当然作为犯罪数额认定标准。

### 3. 政府指导价可用于房产占有使用损失

对于被长期占有、出租、转租或控制的房产、商铺、停车场，可以以政府租金指导价作为市场价格参考。

### 4. 控制权丧失是重要起算点

职务侵占、收益转移类案件中，被害单位丧失财产或收益控制权，可以作为侵占既遂和数额起算的重要节点。

## 七、证据清单

| 参数 | 证据 |
| --- | --- |
| 权属 | 房产证、不动产登记、股权资料、司法拍卖资料、受让合同 |
| 托管关系 | 委托管理协议、授权书、业主委托、物业管理资料 |
| 起止时间 | 合同签订日、账户变更日、实际收款日、接管日、刑事立案日 |
| 面积 | 房产证、测绘图、租赁合同、现场图、商户确认 |
| 单价 | 政府指导价、市场租赁合同、鉴定意见、评估报告 |
| 实际使用 | 租户清单、现场照片、水电记录、物业记录 |
| 收益转移 | 银行流水、收据、发票、财务账册、收款账户 |
| 关联关系 | 工商档案、股权结构、任职信息、印章控制 |

## 八、输出格式

犯罪数额核算输出应至少包含：

1. 核算总额。
2. 核算截止日。
3. 阶段划分。
4. 各阶段小计。
5. 每项公式。
6. 参数来源。
7. 证据附件。
8. 待查事项。
9. 风险提示。

## 九、数值复核规则

生成或审查犯罪数额核算表时，必须检查：

- 分项金额是否等于公式计算结果。
- 小计是否等于各分项合计。
- 总计是否等于各阶段合计。
- 月数是否与起止日期匹配。
- 单价是否对应正确年份、区域、楼层、用途。
- 面积口径是否统一，房产证面积和实际使用面积是否混用。
- 已付款、已返还、成本、残值是否需要扣除。
- 暂计金额是否注明最终计至行为停止之日。
- 是否出现联系方式、完整身份证号、银行卡号等敏感信息。

## 十、进入 Skill 的规则

当用户输入“犯罪数额怎么算”“职务侵占数额核算”“经营收益被侵占”“物业租金收益损失”“按政府指导价计算”“数额犯类案”“销赃金额和犯罪数额不一致”“被害单位实际损失”“退赔金额核算”等内容时，skill 应进入犯罪数额核算模式。

优先输出：

```text
核算对象
→ 起止期间
→ 核算公式
→ 参数证据
→ 分项表
→ 总额
→ 类案/法律依据
→ 待补证据
→ 数值复核提示
```
