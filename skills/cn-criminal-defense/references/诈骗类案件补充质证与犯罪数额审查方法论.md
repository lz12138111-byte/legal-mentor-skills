# 诈骗类案件补充质证与犯罪数额审查方法论

## 一、适用场景

适用于诈骗罪、合同诈骗罪及以服务费、推广费、代理费、运营费、代办费为涉案款项的案件，特别适用于一审庭后公诉机关补充提交询问笔录、辨认材料、资金流水或业务资料的情形。

## 二、核心方法

```text
先限定新增证据的证明内容
→ 再让新增证据反向攻击控方推定
→ 还原合同外委托或实际履约关系
→ 逐笔核对资金用途
→ 扣除已履行、合理支出和已返还款项
```

## 三、新证据四栏表

| 新增证据 | 直接证明事项 | 控方原推定 | 辩方反向用途 |
| --- | --- | --- | --- |
| 关联人员询问笔录 | 收款后安排运营、推广、达人 | 收款后未履约、个人消费 | 证明存在实际服务和履约行为 |
| 辨认表、达人名单 | 存在第三方推广人员 | 费用去向不明 | 证明转委托或自行推广 |
| 银行、微信流水 | 向推广公司或达人付款 | 收款全部归个人 | 证明部分费用用于业务成本 |
| 账务明细、双方确认 | 已返还部分款项 | 按总收款计算诈骗金额 | 扣除已返还款和实际损失 |

## 四、合同外服务的民刑切割

原合同未约定某项服务，不等于额外收款当然是诈骗。应当审查：

- 双方是否存在口头、微信或交易习惯形成的另行委托；
- 被害人是否知道推广目标、服务内容和预计效果；
- 是否认可效果后再付款；
- 行为人是否安排第三方、达人、运营人员提供服务；
- 服务是否实际发生、部分发生或因效果争议未完成；
- 收款是否与具体服务和成本支出相对应。

只要存在真实的另行委托和履约基础，就不能仅以“超出原合同范围”推导非法占有目的。

## 五、资金用途闭环

对收款用途至少分为：

1. 转委托费用；
2. 自行推广成本；
3. 运营、设计、达人、平台费用；
4. 已退还款项；
5. 个人消费；
6. 尚未查明用途的款项。

控方必须证明每一笔被计入诈骗金额的款项都具有非法占有性质。不能因为部分款项用途不明或存在个人消费，就把全部收款推定为诈骗金额。

## 六、犯罪金额核算

建立逐笔核算表：

| 收款 | 对应服务 | 实际业务支出 | 已返还 | 待核金额 | 是否计入犯罪金额 |
| --- | --- | --- | --- | --- | --- |
| 收款A | 运营推广 | 需核对 | 已返还B | A-B | 至少先扣除已返还部分B |
| 其他推广费 | 另行委托 | 待核金额C |  |  | 对应业务支出应审查扣除 |

数额审查顺序：

```text
总收款
− 已实际履行对应部分
− 合理转委托和业务支出
− 已返还款项
− 不具有非法占有性质的其他款项
＝ 可能具有刑法评价意义的金额
```

具体案件仍需结合起诉罪名、司法解释和裁判规则核对“犯罪金额”“违法所得”“实际损失”三者是否具有相同或不同口径。

## 七、庭后补充质证意见结构

```text
开篇：坚持原有意见，限定本次仅回应新证据

一、新证据证明合同外服务和另行委托

二、新证据证明转委托、自行推广和资金合理用途

三、逐笔纠正已返还款及其他犯罪金额
```

表达要求：每一段都应回答“这份证据证明了什么”“它改变了控方哪一项推定”“因此应当作出什么具体处理”。

## 八、进入 skill 的稳定规则

1. 庭后补证优先做增量质证，不重复已经提交的完整辩护意见。
2. 对服务费、推广费、代理费，必须审查合同外另行委托和实际履约。
3. 对资金用途，必须区分转委托、自行履约、合理业务成本、个人消费、退款和用途不明。
4. 部分真实支出足以产生合理怀疑时，应先争取对应金额扣减，再保留全案无罪和量刑备用意见。
5. 已返还款项不能机械按总收款重复计算，应在犯罪金额、违法所得和退赔情节三个层面分别核对。
6. 新证据的质证目标不是只证明“笔录不真实”，也可以承认其真实性并改变其法律证明方向。

## 九、证据形成方式与罪名对象切换

庭后补证还应增加两类审查：证据是如何形成的，以及同一组资金事实在不同罪名下的财产对象是否成立。

### 1. 书面问答和证人材料

对“警方提出问题、证人书面回答、之后再制作笔录”的材料，审查形成时间、询问地点、承办人员、签字人数、附件来源和证人是否独立陈述。即使不当然排除，也应降低其单独证明力，并要求客观证据印证。

对被害单位员工证言，应审查劳动关系、职务压力、利益关联和是否存在指使、暗示或其他外部影响，不能仅凭员工身份作无效结论，也不能未经印证直接作为定案基础。

对个人提交的银行流水，重点审查完整性、账户期间、是否选择性打印、是否缺少对公和关联账户数据。

### 2. 诈骗与职务侵占的对象审查

当控方在诈骗、职务侵占之间切换时，应分别制作财产对象表：

```text
诈骗：谁基于错误认识处分了什么财产
职务侵占：什么财产属于单位，行为人如何基于职务占有
民事纠纷：双方合同费用、服务成果、退款和清算如何处理
```

个人账户付款不能当然等于单位财产；公司员工或法定代表人代为付款时，应核查资金来源、授权、报销、会计入账和最终归属。

### 3. 虚假凭证的错误认识审查

凭证可能不真实，不等于当然构成诈骗手段。应拆成：凭证是否虚假、谁要求提供、用途是什么、对方是否知情、是否因真假产生错误认识、是否基于该错误处分财产，以及是否可能构成其他责任。

## 十、一审辩护词：双罪名与部分认罪的三级结构

当同一组运营、收款和个人账户事实被同时评价为职务侵占罪和诈骗罪时，应分别建立两套要件表，不能让控方在罪名之间自由切换：

```text
职务侵占：工作人员身份 → 职务便利 → 单位财产 → 非法占有
诈骗：欺骗行为 → 错误认识 → 财产处分 → 损失/非法占有目的
```

一审辩护词推荐采用三级结构：

1. **主位无罪**：攻击身份要件、财产对象、欺骗因果、实际履约和非法占有目的。
2. **次位减额或罪名替代**：对真实服务费、业务成本、第三方收款、已返还款和证据不能闭环的项目逐项扣除；对暂时使用资金的事实保留挪用或民事责任的备用论证，但不得未经要件审查直接替代罪名。
3. **末位量刑**：对证据明确且不宜继续争议的部分主动限定认罪范围，同时提出退赔、坦白、认罪认罚、初犯和缓刑理由。

### 1. 身份和财产对象的双重审查

劳动合同、工资、社保、个人账户付款和公司负责人证言，应放进同一张身份与财产表：

| 争点 | 需要核对的证据 |
| --- | --- |
| 是否为单位工作人员 | 实际管理、考勤、工作指令、组织关系、报酬方式 |
| 款项是否属于单位财产 | 来源、账户性质、会计记账、授权、报销和最终归属 |
| 是否存在个人与公司混同 | 个人账户同时收付公私款、账簿、纳税和完整流水 |
| 是否基于职务占有 | 收款权限、保管权限、转款决定和实际控制范围 |

个人账户混合收支只能形成重大疑问，不能直接推出公司没有独立财产；辩护请求应同步提出调取完整流水、账簿和会计凭证。

### 2. 服务型诈骗的金额核算闭环

每笔收款至少形成以下链条：

```text
付款主体 → 付款依据 → 约定服务 → 实际履行 → 业务支出 → 第三方收款/返款 → 已退金额 → 最终占有
```

对第三方佣金，要单独核对：被害人是否知情并同意、第三方是否实际提供服务、第三方收款是否由行为人控制、返款是否与被害人财产处分存在直接因果。第三方先收款并不自动排除共犯或利益计算，但控方不能跳过这些证明环节。

对保险理赔、平台赔付等款项，要同时核查平台原始记录、赔付金额、实际收款主体、返还记录和行为人是否具有暂时使用后归还的意思。金额证据不足与主观故意不足是两条不同论证线。

### 3. 诉讼表达的“法官索引版”

完整辩护词可以保留事实和法律展开，但庭审发言、书面摘要和案件分析卡应压缩为：

```text
争点编号 → 罪名要件 → 关键证据页码 → 控方推定 → 辩方反证 → 具体请求
```

每个争点只保留一条主结论和一条备用结论。篇幅越长，越需要把金额表、证据页码和请求前置，否则真实服务、第三方佣金、退款项目等有利事实会被大量法理论述稀释。

## 十一、进入 skill 的补充规则

1. 一审遇到双罪名指控时，先做罪名要件分流，不允许用诈骗的财产处分逻辑替代职务侵占的单位财产逻辑。
2. 任何金额排除都要绑定付款主体、法律关系、实际履行、资金归属和原始证据。
3. 对第三方佣金和返款，分别判断“被害人损失”“行为人占有”“共同犯罪利益”和“量刑退赔”，四者不能混为一谈。
4. 对保险理赔或平台赔付，先审客观金额，再审收款和返还，再审诈骗与挪用的主观区别。
5. 辩护方案默认同时生成主位无罪、次位金额扣减/罪名备用、末位量刑三组请求，但要明确各组的事实前提，避免逻辑互相冲突。

## 十二、补充侦查后的法律意见与羁押必要性联动

审查起诉阶段收到补充侦查材料后，应采用“增量回应”而非重复全文辩护的方式：

```text
新增证据 → 改变控方推定 → 影响罪名/金额 → 影响可能刑期 → 影响羁押必要性
```

推荐按以下四类新增事实组织：

1. **实际履约材料**：达人名单、发布时间、消费链接、平台曝光、转委托付款和服务商证言，证明收款有真实服务基础；
2. **财务和凭证材料**：区分凭证真伪、制作用途、被害人知情程度及是否因凭证真假作出新的财产处分；
3. **平台结算和第三方佣金**：拆分被害人付款、第三方实际收款、行为人返款和行为人最终占有，不能用平台总流水替代犯罪金额闭环；
4. **赔偿和监管材料**：退赔凭证、还款方案、保证人和居住信息，直接服务于“证据已固定、无社会危险性、可能判缓刑”的羁押必要性判断。

补充法律意见的每一部分都应有双重落点：前半段说明为什么不能按控方罪名或金额认定，后半段说明即使仍需核查，剩余工作也不依赖继续羁押即可完成。

### 理赔和平台赔付的专项检查

对于食品安全险、平台赔付、商家补偿等款项，建立五栏表：

| 金额 | 平台原始记录 | 实际收款主体 | 返还/补回 | 主观目的 |
| --- | --- | --- | --- | --- |
| 起诉意见书金额 | 订单、赔付截图、平台流水 | aa、公司或第三方 | 已返金额和时间 | 暂时周转或永久占有 |

先纠正金额证据，再讨论诈骗与挪用、职务侵占或民事责任的区分。主张罪名切换时，必须补齐对应罪名的主体、对象和行为要件。
