# 审查起诉阶段无罪证据调取与不起诉方法论

## 一、适用场景

适用于案件已移送审查起诉，辩方认为存在无罪、罪轻或犯罪阻却事由，但关键证据掌握在侦查机关、银行、公司、第三人或需要司法审计才能查明的场景。

典型包括：

- 形式违法行为存在，但行为目的、背景和法益侵害存在重大争议。
- 当事人主张紧急避险、正当防卫、正当维权、被害人承诺、缺乏非法占有目的等阻却事由。
- 关键事实依赖资金流水、公司账册、合同流、业务流、审计报告等客观材料。
- 公安移送材料偏重有罪证据，未充分收集无罪或罪轻证据。

## 二、核心打法

不要一上来只喊“不起诉”。先把不起诉结论拆成检察院必须查明的证据问题。

```text
形式行为存在
→ 找到阻却犯罪或影响起诉必要性的关键事实
→ 说明该事实为什么属于无罪/罪轻证据
→ 列明证据线索和调取对象
→ 请求检察院调取、审计、退补或自行补查
→ 为不起诉意见铺路
```

当证据基础已经相对充分时，可以从“调取无罪证据申请”升级为“实体不起诉法律意见”。实体意见不再只要求检察院查明事实，而要直接完成法律评价。

```text
形式行为
→ 主位阻却犯罪评价
→ 前置法/法秩序统一性补强
→ 自首、坦白、情节轻微等兜底
→ 请求不起诉
```

## 三、文书结构

### 1. 标题

标题可以直接使用“不予起诉申请书”，但正文第一请求宜落在“申请查明事实”“申请调取证据”“申请司法审计”上。

### 2. 开头

开头交代：

- 辩护人身份
- 案件罪名
- 移送审查起诉时间
- 本次申请的具体事实或证据对象

### 3. 法律依据

常用依据包括：

- 辩护人申请调取无罪、罪轻证据的权利
- 司法机关全面收集有罪、无罪、罪轻、罪重证据的义务
- 检察院审查起诉阶段查明犯罪性质、罪名、量刑情节和共同犯罪责任的职责

引用法律不是为了堆砌，而是为了把“辩方请求”变成“检察机关审查起诉职责”。

### 4. 事实连接

必须说明：

- 该证据要证明什么事实
- 该事实为什么影响罪与非罪、此罪与彼罪或起诉必要性
- 不调取该证据会导致什么审查缺口

### 5. 证据线索

调证请求必须具体：

- 调取对象：个人账户、公司账户、合同、账册、发票、聊天记录、审批文件等
- 调取范围：时间段、账户、主体、业务项目
- 审查目标：是否收款、是否截留、是否占有、是否虚构债务、是否关联交易
- 使用方式：结合辩方证据、司法审计、补充侦查或自行补查

## 四、紧急避险类案件的证据化

主张紧急避险时，不能停留在“情有可原”。至少要证明五件事：

1. 正在发生的危险是什么。
2. 危险是否针对公司、本人或他人的合法权益。
3. 行为人是否尝试过合法救济。
4. 为什么当时不得已采取被指控行为。
5. 被指控行为造成的损害与所避免的损害如何比较。

在公司公章、控制权、财产侵占类案件中，重点证据通常是：

- 真实公章由谁控制。
- 控章人是否签订虚假合同、虚构债务、低价处分资产。
- 公司业务款是否进入个人账户或关联公司账户。
- 当事人是否报案、起诉、申请监管介入或发函维权。
- 被指控行为是否只用于制止侵害，而非另行牟利。

实体不起诉意见中，紧急避险最好按以下顺序写：

1. 正在发生的现实危险。
2. 行为人对被保护法益负有职责或具有正当利益。
3. 行为人已经尝试合法救济但未能制止危险。
4. 被指控行为为什么是不得已的必要措施。
5. 被指控行为是否用途受限、时间受限、对象受限。
6. 是否未超过必要限度、未造成不应有损害。

这一路径可以避免文书只停留在“动机良好”，而是让承办人按紧急避险要件审查。

## 五、法秩序统一性补强

当案件发生在公司治理、财产管理、用章管理、合同履行等前置法律关系中，可以用法秩序统一性作为补强论证。

可用结构：

```text
前置法确认行为人具有某种职责或权利
→ 行为人实施行为是为了履行该职责或保护该权利
→ 刑法评价不应与前置法允许或鼓励的行为相冲突
→ 正当维权行为不应被认定为犯罪
```

注意：法秩序统一性通常不是唯一主攻点，最好与紧急避险、缺乏非法目的、未造成实害等实体理由组合使用。

## 六、司法审计请求的写法

司法审计不能笼统请求“查账”。应当写成：

```text
请调取A、B、C主体在某期间的银行流水，
并结合辩方已提交的证据编号X-Y，
对某些主体是否占有公司财产、占有金额、资金路径、资金去向进行司法审计。
```

可审计对象包括：

- 私账收款
- 截留公司业务款
- 关联公司转移收益
- 虚构债务付款
- 低价处分资产后的利益流向
- 个人账户与公司业务之间的异常往来

## 七、三层不起诉结构

对于形式行为确实存在，但刑事评价有争议的案件，可以采用三层结构：

1. 主位无罪：紧急避险、正当防卫、正当维权、缺乏构成要件、无违法性或责任阻却。
2. 补强无罪：前置法职责、法秩序统一性、法益未受损、行为限度适当。
3. 兜底从宽：自首、坦白、认罪认罚、初犯偶犯、情节显著轻微、危害不大。

这种结构的优点是，不会因检察院暂不接受无罪观点而失去从宽空间。

## 八、表达风格

老师的表达不是“控诉式”，而是“审查义务式”：

- “申请贵院查明以下事实”
- “该事实属于本案应当查明的无罪证据”
- “为确保司法审查结果公平公正，特申请调取、查明”
- “该事实关系犯罪阻却事由能否成立”

这种表达能降低对抗性，也让承办人更容易把材料纳入审查起诉工作流。

在实体不起诉意见中，表达可以更坚定，但仍应保持审查语言：

- “应属紧急避险，不应负刑事责任”
- “不具有刑法违法性，排斥认定犯罪”
- “即便不采纳无罪意见，亦应评价自首等从宽情节”

## 九、风险控制

- 不要把第三人涉嫌犯罪写成未经证明的确定结论，除非已有充分证据。
- 不要泄露完整手机号、银行账号、身份证号等敏感信息。
- 不要泛泛申请调取所有账户、所有资料，要说明具体线索。
- 不要只讲情理，必须把情理落到证据和构成要件。
- 不要忽视被指控行为本身的风险，应解释其必要性、限度和目的。

## 十、医保骗保类诈骗的专项补充

医疗机构骗保案件应在不起诉意见中增加三张表：

1. 患者级别的挂床认定表：住院手续、真实诊疗、离院/请假、病历护理、费用记录、医保协议具体条款；
2. 人员责任矩阵：组织经营、病历制作、财务采购、医保审核、资料上传、实际获利和合规反向行为；
3. 基金损失核算表：结算单申报、真实合法费用、审核扣减、年度清算、行政追回、医院退款和实际拨付。

患者不在院、上传病历或结算单记载基金支付金额，均不能单独完成诈骗罪的事实和主观要件证明。应先完成医保前置规则、刑事行为、共同故意和实际损失的分层，再提出证据不足不起诉、酌定不起诉及取保的层级请求。

## 十一、可复用输出模板

```text
申请人民检察院查明以下事实：
调取【主体/账户/资料】，
并结合辩护人提交的【证据编号/材料名称】，
对【待证事实】进行司法审计/调查核实。

本案确有证据证明，【背景事实】。
犯罪嫌疑人【姓名】为制止【不法侵害/危险状态】，
在【合法救济情况】后，
不得已采取【被指控行为】。
因此，【待证事实】属于本案应当查明的无罪证据/罪轻证据/犯罪阻却事由。
为确保本案司法审查结果公平公正，特申请贵院依法调取、查明。
```

实体不起诉意见模板：

```text
一、【行为】系为了使【法益】免受正在发生的危险而采取的紧急避险行为
（一）【被保护法益】面临正在发生的现实危险。
（二）行为人负有【职责/权利基础】，已积极维权无果。
（三）【被指控行为】系制止危险的不得已措施。
（四）行为未超过必要限度，未造成不应有损害。

二、合法维权行为排斥认定犯罪，系法秩序统一性原理的基本要求

三、即便不采纳无罪意见，行为人仍具有【自首/坦白/情节轻微】等从宽情节
```

## 十二、进入 skill 的稳定规则

1. 审查起诉阶段出现关键无罪证据未调取时，优先生成“调取无罪证据申请 + 不起诉方向”的组合文书。
2. 对容易被形式认定的罪名，必须补做行为背景、主观目的、法益损害、阻却事由四项审查。
3. 公司财产争议案件中，账户流水和司法审计往往是把“维权说法”变成“无罪证据”的关键。
4. 请求事项必须可执行：谁的什么账户、什么期间、结合哪些证据、审计什么问题。
5. 文书结尾要把调证目的落到不起诉审查，而不是停留在取证本身。
6. 证据基础充分时，应从调证申请升级为实体不起诉法律意见，并采用“主位无罪、补强无罪、兜底从宽”的结构。
