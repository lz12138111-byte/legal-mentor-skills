# 法院执行监督方法论

## 一、用途

本文件用于沉淀老师在执行程序中向上级法院申请督促下级法院终结执行、解除执行措施、纠正消极执行或怠于处理申请的方法。尤其适用于刑民执行交叉、拒执罪关联执行案、公司公章/控制权争议等场景。

## 二、适用场景

适合使用：

1. 申请执行人已撤销执行申请。
2. 被执行义务已经履行或执行目的已经实现。
3. 下级法院迟迟不作终结执行裁定。
4. 查封、冻结、失信、限高等执行措施仍持续影响当事人。
5. 执行基础变化与刑事案件、公司治理或紧急避险背景有关。

## 三、基础工作流

```text
确认执行依据和义务内容
→ 确认申请执行人撤销执行或义务已履行
→ 梳理下级法院怠于处理表现
→ 说明继续执行的不当后果
→ 引用终结执行和执行督办依据
→ 请求上级法院督促终结执行并解除措施
```

## 四、审查清单

1. 执行依据确定的义务是什么？
2. 申请执行人是否已撤销执行？
3. 被执行人是否已经履行义务？
4. 执行目的是否已经实现？
5. 下级法院是否未裁定终结、未解除措施或未回复申请？
6. 继续执行是否会造成明显不正义结果？
7. 是否需要与公安撤销拒执案、解除网逃或强制措施联动？

## 五、文书结构

```text
申请事项
→ 执行案基本情况
→ 执行基础变化
→ 当事人已提交申请
→ 下级法院怠于处理
→ 终结执行法律依据
→ 继续执行的不正义后果
→ 上级法院督办依据
→ 具体请求
```

## 六、写作规则

1. 先讲法定终结事由，再讲执行正义。
2. 不否认原执行依据，而是说明终结事由已经出现。
3. 当事人申请、撤销、履行等程序动作要附件化。
4. 请求事项要具体列出：终结执行、解除查封冻结、解除失信、解除限高等。
5. 情绪性或反问式表达应后置，用于强化而非替代法律依据。
