# 刑事被害人退赔损失核算方法论

## 一、用途

本文件用于沉淀老师在刑事案件中代表被害人或被害单位，就赃物灭失、低价强迫交易、财产价值被低估、退赔金额不足等问题，向法院或检察院提出损失核算和责令退赔意见的方法。

这类文书的核心不是追诉新事实，而是把“被告人违法所得”与“被害人实际损失”区分开，争取法院按更接近民事损害填补的方式确定退赔金额。

## 二、基础工作流

```text
确认被害人代理身份
→ 确认起诉书或裁判对损失金额的认定
→ 区分无争议损失和争议损失
→ 攻击原核价方式
→ 建立替代核价方法
→ 梳理价格、数量、使用年限、成新率等证据
→ 必要时申请法院调取关键证据
→ 落到明确退赔金额和利息/孳息主张
```

## 三、核心审查清单

### 1. 原损失认定

- 起诉书或判决认定的损失金额是多少？
- 该金额是按被告人获利、交易差价、市场价、鉴定价还是被害人陈述计算？
- 被害人对哪些部分无异议，哪些部分有异议？
- 原核价方式是否以意向价格、低价变现价格、关联交易价格、未实际成交价格作为依据？

### 2. 替代核价方法

- 赃物是否尚在？能否追缴原物？
- 若赃物灭失或无法追缴，是否应折价退赔？
- 应按损失发生时市场价格、实际购买价、评估价、残值、收益损失还是其他合理方式计算？
- 固定资产是否需要考虑使用年限、剩余年限、折旧、成新率？
- 是否存在型号、批次、购买时间不同，需要分组计算？

### 3. 证据体系

- 购买合同、发票、银行流水、贷款资料是否能证明原始购买价？
- 证人证言、厂家说明、同类设备使用情况是否能证明使用年限和市场行情？
- 税务机关、银行、交易对手处是否保存关键资料？
- 被害人无法自行调取时，是否应申请法院或检察院调取？
- 是否需要鉴定、评估或补充审计？

### 4. 刑民规则竞合

- 刑法第六十四条追缴、退赔规则是否可作为基础？
- 民法典财产损害赔偿规则是否可用于确定损失金额？
- 退赔问题是否具有民事赔偿属性？
- 刑事判决认定的赃款数额是否小于被害人实际损失？
- 是否需要区分刑事定罪量刑证明标准与民事赔偿高度盖然性标准？

## 四、文书结构

```text
一、刑事退赔兼具民事赔偿性质
二、起诉书/原认定对损失金额的核价方式错误
三、应采用的替代核价方法
四、替代核价方法的事实和证据依据
五、需要法院/检察院调取的关键证据
六、最终退赔金额、利息或孳息主张
七、具体请求
```

## 五、常用论证模块

### 1. 否定意向价格

```text
拟出售价格未实际成交
→ 交易对象并非被告人
→ 低价出售存在特定应急背景
→ 不能代表损失发生时市场价格
→ 应回到客观市场价值或合理折价方法
```

### 2. 固定资产残值核算

```text
确认设备原始购买价
→ 确认购买时间和数量
→ 确认合理使用年限
→ 确认案发时已使用年限
→ 折算剩余使用年限对应残值
→ 扣除被告人已支付款项
→ 得出被害人损失金额
```

### 3. 调取证据衔接

```text
现有证据只能证明部分价格
→ 完整资料在税务、银行、交易对手或行政机关处
→ 被害人无法自行收集
→ 诉讼代理人依法可申请法院调取
→ 调取目的直接服务于损失金额认定
```

## 六、表达规则

1. 先定性退赔问题，再争具体金额。
2. 不只说“金额太低”，必须指出原核价方法为什么错。
3. 替代算法要同时具备法律依据、商业常识和证据支撑。
4. 涉及复杂计算时，应列明每个参数来源。
5. 对被告人已支付款项、已返还财物应主动扣除，增强可信度。
6. 若主张利息、孳息，应单独说明法律依据和计算标准。
7. 文书提交前必须做数值一致性检查，避免标题金额、过程金额、结论金额不一致。

## 七、数值复核规则

生成此类文书或分析时，skill 必须提示律师复核：

- 单价、数量、总价是否匹配。
- 已付款、已返还金额是否扣除。
- 年限、折旧、残值计算是否一致。
- 文中不同位置的最终损失金额是否一致。
- 本金、利息、总额是否能相互对应。
- 是否存在不同型号、不同购买年份却用平均单价造成争议的风险。

## 八、与其他被害人文书的关系

```text
追诉遗漏犯罪事实：解决追谁、追什么事实。
持续侵害制止：解决正在发生的财产控制和损害扩大。
诉讼权利保障申诉：解决拿不到案件资料。
退赔损失核算意见：解决法院最终判多少钱、怎么退赔。
调取证据申请：为退赔金额补齐关键证据。
```
