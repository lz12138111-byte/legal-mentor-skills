# 重大事项升级沟通方法论

## 一、用途

本文件用于沉淀老师在刑事案件中向承办机关领导层提交紧急报告、重大事项报告、督促复核函等沟通型文书的方法。该类文书不替代正式法律意见，而是在正式意见已提交、承办层面反馈不利或时间紧迫时，用于提示重大事实、证据、程序或量刑问题。

## 二、适用条件

适合使用：

1. 已提交正式法律意见、申请书或辩护意见。
2. 已与承办人员进行正常沟通。
3. 承办层面反馈不利，或可能存在重大事实、证据、法律适用偏差。
4. 问题足以影响定罪、罪名、量刑、强制措施、追诉范围或重大程序权利。
5. 时间节点紧迫，需要领导层督促复核。

不适合使用：

1. 尚未正常提交意见即越级沟通。
2. 只是重复普通辩护观点。
3. 缺少证据支撑。
4. 主要目的是情绪表达或施压。
5. 文书可能破坏与承办机关的基本沟通关系。

## 三、基础结构

```text
身份和案件信息
→ 已提交正式意见和沟通情况
→ 当前不利反馈或紧急原因
→ 核心问题摘要
→ 问题的重大影响
→ 政策、职责或程序依据
→ 克制请求
→ 附件
```

## 四、写作规则

1. 正文要短，详细论证放附件。
2. 先说明已走正常沟通程序，避免显得绕开承办人。
3. 不直接攻击承办人员或上级机关。
4. 将问题表述为“需要慎重核实”的重大事项。
5. 请求动作应克制，例如“督促核实”“依法处理”“审慎审查”。
6. 可适度引用机关系统内部政策语言，但必须服务于个案证据核实。
7. 不使用未经核验的具体领导讲话、政策表述或会议内容。

## 五、风险控制

- 称谓要符合当下办案机关沟通习惯。
- 语气礼貌但不卑弱。
- 不夸大案件影响。
- 不将承办意见描述为违法，除非已有充分依据。
- 不把沟通型文书当作正式法律意见替代品。
