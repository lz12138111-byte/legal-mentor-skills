# 公安依法履职督促方法论

## 一、用途

本文件用于沉淀老师在公安机关怠于撤案、解除强制措施、回应申请、制止侵害或履行其他法定职责时，通过纪检监察、上级公安、检察监督等路径申请督促纠正的方法。

## 二、适用场景

适合使用：

1. 当事人已向公安机关提出撤案、解除措施、返还财物、制止侵害等申请。
2. 公安机关长期不处理、不回复或明显拖延。
3. 案件事实基础、民事执行基础或程序基础已经发生重大变化。
4. 继续维持案件或措施会造成当事人现实权益危险。
5. 需要外部监督机关督促公安依法履职。

## 三、基础工作流

```text
确认公安机关具体职责
→ 确认当事人已提交申请
→ 梳理事实或程序基础变化
→ 说明公安机关怠于履职表现
→ 说明当事人权益紧迫风险
→ 选择监督路径
→ 请求督促纠正
```

## 四、刑民执行交叉拒执案件审查清单

1. 执行依据确定的义务是什么？
2. 义务是否已经实际履行？
3. 申请执行人是否申请撤销强制执行？
4. 执行程序是否应终结或已经终结？
5. 未履行是否存在紧急避险、权利冲突或正当理由？
6. 继续侦查拒执罪是否仍有现实必要？
7. 当事人是否已申请撤案、解除网逃或解除强制措施？
8. 公安机关是否未回复、未处理或拖延履职？
9. 是否需要从“公安怠于履职”进一步转化为“检察院监督不应当立案而立案”？

## 五、文书结构

```text
一、说明被监督机关和案件
二、指出怠于履职事项
三、说明事实或程序基础变化
四、说明当事人已提出申请
五、说明公安机关未处理、未回复
六、说明权益紧迫危险
七、请求监督机关督促纠正
```

## 六、写作规则

1. 不只写“公安不作为”，要写清应履行的具体职责。
2. 不只写“案件不应继续”，要写清事实基础如何变化。
3. 当事人已提交的申请要附件化、证据化。
4. 请求事项要具体，例如撤案、解除网逃、解除强制措施、回复申请。
5. 对法律结论保留审慎空间，避免绝对化。

## 七、与刑事立案监督的区分

公安依法履职督促强调公安已经负有撤案、解除措施、回复申请等具体职责，但未及时处理；刑事立案监督强调公安立案本身不应成立，需请求检察院审查“不应当立案而立案”并监督撤案。

同一案件中，若公安长期不回复，可以先用履职督促；若已有明确材料证明立案基础不成立或事实基础已经变化，则应转入刑事立案监督路径。

## 八、与拒执罪撤案共同意见的关系

拒执罪撤案共同意见通常直接提交公安机关，重点在于被立案人一方与申请执行人/被害单位一方形成共同撤案立场，证明未履行行为具有紧急避险或正当维权性质、执行义务已履行、继续追诉无现实必要。

若公安收到共同法律意见后仍不处理、不回复，再转入公安依法履职督促或检察立案监督路径。
