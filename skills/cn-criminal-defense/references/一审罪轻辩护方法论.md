# 一审罪轻辩护方法论

## 一、用途

本文件用于沉淀老师在一审阶段进行罪轻辩护、量刑辩护、认罪认罚后庭审辩护的方法。适用于不主攻无罪，而以法定和酌定从宽情节争取较轻刑罚的案件。

## 二、基础工作流

```text
判断是否接受基本定罪
→ 选择最强法定从宽情节
→ 用证据支撑法定情节
→ 叠加酌定从宽情节
→ 处理不利事实
→ 协调认罪认罚和庭审辩护
→ 谨慎加入情理表达
→ 提出明确量刑方向
```

## 三、罪轻辩护排序

优先顺序通常为：

1. 自首、准自首、立功、从犯等法定情节。
2. 坦白、如实供述、认罪认罚等到案后表现。
3. 退赃退赔、赔偿谅解、修复损害等社会修复情节。
4. 积极配合调查、认错悔错等态度情节。
5. 家庭困难、身体状况、社会关系等个别化因素。

## 四、法定情节论证规则

### 1. 准自首/以自首论

固定审查：

- 办案机关到案前掌握的是什么事实？
- 是否为主要犯罪事实？
- 已掌握事实与起诉指控事实在罪名、主体、利益方向、款项流向上是否一致？
- 被告人供述的新增事实对定罪或量刑是否重大？

### 2. 从犯

固定审查：

- 犯意来源
- 职权资源
- 行为支配
- 金额指标
- 分配决定权
- 具体实施行为是否受他人概括犯意或整体支配

## 五、同案多阶段改写规则

同一案件的同一事实，应按程序阶段改写：

```text
审查起诉阶段：争取检察机关量刑建议
一审阶段：争取法院裁判采纳
二审阶段：攻击一审未采纳的理由
```

不要在不同阶段机械复制同一段文字。应根据说服对象和文书任务调整语气、结构和攻击性。

## 六、情理表达规则

1. 放在法定和重要酌定情节之后。
2. 不替代法律论证。
3. 先承认犯罪严重性，再请求宽缓。
4. 服务于刑罚个别化、社会修复和家庭责任。
5. 避免煽情过度。
