# 拒执罪撤案共同法律意见方法论

## 一、用途

本文件用于沉淀老师在拒不执行判决、裁定罪案件中，同时取得被立案人一方与申请执行人/被害单位一方共同立场，向公安机关请求撤案、解除刑事措施的方法。

这类文书的核心价值在于重构当事人关系：原本被描述为“抗拒执行”的行为，在新的事实背景下可能实际保护了申请执行人的利益；当申请执行人也认可不追究时，拒执罪继续侦查的正当性明显削弱。

## 二、基础工作流

```text
确认拒执案执行义务
→ 还原执行义务背后的真实权利结构
→ 查明继续执行是否损害申请执行人利益
→ 证明未履行行为具有紧急避险、权利冲突或正当维权性质
→ 证明执行义务已经实际履行或执行目的已经实现
→ 固定申请执行人/被害单位不追究或请求撤案的明确立场
→ 双方代理人共同向公安提交法律意见
→ 请求撤案并解除刑事强制措施
```

## 三、核心审查清单

### 1. 执行义务

- 原生效判决、裁定确定了什么义务？
- 拒执案是因未履行哪项义务而立案？
- 该义务是否涉及公司公章、证照、账册、房产、股权或控制权？
- 义务后来是否已经实际履行？

### 2. 真实利益结构

- 申请执行人名义上是谁？
- 当时控制申请执行人的人是否与公司真实利益一致？
- 是否存在原控制人利用公司名义侵害公司利益的情况？
- 被执行人不履行行为是否实际保护了申请执行人或公司利益？

### 3. 紧急避险或正当维权

- 是否存在正在发生的财产危险？
- 被执行人采取的不履行行为是否为避免危险所必需？
- 是否避免了更大损失？
- 是否能用后续刑事立案、批捕、侦查材料、股东会决议、印章交接证明等证据支撑？

### 4. 共同撤案基础

- 申请执行人/被害单位是否由新管理层有效代表？
- 是否有股东会决议、法定代表人变更、印章交接等材料？
- 申请执行人是否确认不追究？
- 是否已向公安提交撤案申请？
- 是否需要双方代理律师共同签署法律意见？

## 四、文书结构

```text
一、双方代理身份和共同意见基础
二、原执行案与拒执案基本情况
三、后续查明的侵害申请执行人利益事实
四、不履行行为为何属于紧急避险或正当维权
五、执行义务已履行、执行目的已实现
六、申请执行人/被害单位确认不追究
七、请求公安撤案并解除刑事强制措施
```

## 五、表达规则

1. 先展示共同立场，说明不是单方抗辩。
2. 不把拒执行为孤立看待，要放回基础法律关系和真实利益结构中评价。
3. 紧急避险论证要包含危险来源、避险行为、保护利益、避免结果。
4. 强调拒执罪保护的是裁判权威和申请执行人权益，若申请执行人权益已被保护，继续追诉必要性下降。
5. 结尾请求要具体到撤销立案、解除网逃、解除强制措施、书面回复等。

## 六、与相邻文书的关系

```text
撤销刑事案件申请：直接由当事人或代理人向公安申请撤案、解除网逃或强制措施。
共同法律意见：直接提交公安，争取主动撤案。
公安履职督促：公安不处理共同意见和撤案申请时使用。
法院执行监督：执行程序仍未终结或执行措施仍未解除时使用。
刑事立案监督：公安仍不撤案时，请检察院审查不应当立案而立案。
```

同一拒执案中，共同法律意见通常是较早、较基础的一份材料，后续监督材料可以引用其事实结构。
