# 审查起诉阶段量刑意见方法论

## 一、用途

本文件用于沉淀老师在审查起诉阶段向检察机关提交量刑意见、认罪认罚沟通意见或补充辩护意见的方法。

## 二、基础工作流

```text
识别检察机关即将形成的起诉和量刑方向
→ 找出最能影响量刑建议的法定情节
→ 用案卷证据支撑法定情节
→ 叠加酌定从宽情节
→ 判断是否适合加入情理因素
→ 请求检察机关提出从宽或减轻处罚量刑建议
```

## 三、量刑意见排序

量刑意见的说服顺序应当是：

```text
法定从宽情节
→ 重要酌定情节
→ 认罪认罚态度
→ 社会修复和退赃退赔
→ 家庭困难等情理因素
→ 明确量刑建议请求
```

不要让家庭困难、悔罪表达等情理内容压过法律论证。

## 四、从犯论证“五看”

1. 看犯意来源：谁提出、授意、指使犯罪。
2. 看职权资源：谁掌握项目、审批、验收、资金、人员等关键资源。
3. 看行为支配：谁决定行为方式、对象、金额和节奏。
4. 看金额指标：是否存在上级设定指标、下级完成任务。
5. 看分配决定权：谁决定赃款分配，是否存在前期全额上交或经同意留存。

## 五、情理表达边界

可以使用：

- 年迈父母需要照护
- 未成年子女成长需要
- 长期家庭责任
- 认错悔错和愿意接受处罚
- 积极退赃、配合调查

使用条件：

1. 前面已有法定或重要酌定从宽情节支撑。
2. 情理内容真实、克制、具体。
3. 情理内容服务于刑罚个别化，而不是否认犯罪严重性。
4. 必须承认不利前提时，应先承认再请求宽缓。

## 六、文书结构

```text
一、说明程序阶段和辩护身份
二、提出核心法定量刑情节
三、围绕证据展开事实论证
四、叠加认罪认罚、退赃、配合调查等情节
五、适度提出家庭和社会因素
六、请求检察机关提出从宽或减轻处罚量刑建议
```
