# 被害单位刑事代理方法论

## 一、用途

本文件用于沉淀老师在刑事案件中代表被害人、被害单位提出法律意见、控告、检察监督、补充追诉和追赃挽损请求的方法。该方法论不同于辩护人视角，应单独保留。

## 二、基础工作流

```text
确认代理立场和程序阶段
→ 还原被害单位权利结构
→ 还原行为人职务便利和实际控制关系
→ 梳理财产脱离控制路径
→ 审查起诉意见书或侦查结论偏差
→ 校正被害单位、犯罪数额和事实范围
→ 审查遗漏事实、遗漏罪名、遗漏人员
→ 提出追赃挽损和涉案财物处理请求
→ 提出检察监督或侦查监督请求
```

## 三、核心审查清单

### 1. 被害单位认定

- 被侵害的是谁的财产所有权、占有权、收益权或处分权？
- 行为人利用的是哪一个单位中的职务便利？
- 是否存在多个被害单位、多个财产来源、多个转移阶段？
- 是否不能仅依据合同相对方、收款主体或形式管理主体认定被害单位？

### 2. 财产流与控制关系

- 原始财产权属如何取得？
- 收益权、经营权、管理权如何移转？
- 行为人在哪些公司担任职务或具备实际控制力？
- 关联公司是否为接收资产、转移收益、制造交易流水的工具？
- 是否存在人员、办公、财务、账户、印章、业务混同？

### 3. 犯罪数额

- 被侵占对象是现金、不动产、收益权、债权、股权还是其他财产性利益？
- 应以实际收款、账面收入、合同价、市场价还是评估价计算？
- 行为人为实施犯罪支出的费用是否直接弥补被害单位损失？
- 犯罪行为是否处于持续状态？
- 数额计算截止日是否需要延伸至犯罪行为停止之日？

### 4. 遗漏追诉

- 是否有遗漏犯罪事实？
- 是否有遗漏罪名？
- 是否有遗漏犯罪嫌疑人或共同犯罪人？
- 追加罪名是否具备独立构成要件和证据支撑？
- 能否用既有民事判决、行政处罚、工商档案、银行流水等证据支撑追诉线索？
- 是否存在遗漏犯罪单位或犯罪载体公司？
- 是否应将遗漏事实按类型分组，而不是混合叙述？

### 5. 追赃挽损和程序监督

- 是否已查封、冻结、扣押犯罪所得及孳息？
- 是否存在应冻结而未冻结的账户、房产、股票、有价证券等财产？
- 是否存在持续侵害需要立即制止？
- 被害单位证照、账本、合同、印鉴等合法财产是否应及时返还？
- 侦查机关是否妨碍被害单位依法行使知情权、控告权、申请权、财产权？
- 侦查机关是否未送达法律文书、未告知案件移送情况，导致被害单位无法开展后续维权？
- 是否需要通过检察院申诉控告程序，督促公安机关提供与被害单位维权相关的案件信息资料？

### 6. 持续侵害制止

- 嫌疑人被立案、拘留、逮捕后，关联主体是否仍在继续控制财产？
- 公章、证照、账户、合同、现场人员是否仍可被用于继续侵害？
- 是否存在继续签约、继续收款、第三方代收、折扣免租、延长租期等行为？
- 是否会导致被害单位债权减损、债务增加或与第三人关系复杂化？
- 被害单位已采取哪些自救措施？
- 为什么仅靠自救不足以制止侵害？
- 应请求侦查机关采取哪些具体阻断措施？

## 四、文书结构

被害单位法律意见书可以采用以下结构：

```text
一、案涉基本事实
二、起诉意见书或侦查结论存在的核心偏差
三、犯罪数额或财产损失认定意见
四、遗漏事实、罪名、人员的追诉意见
五、侦查不作为或程序违法监督意见
六、具体请求
```

## 五、表达规则

1. 先建立事实压强，再提出法律观点。
2. 复杂公司案件中，先讲权属，再讲控制，再讲转移。
3. 对检察机关提出意见时，要给出可操作的监督抓手。
4. 追诉遗漏时，要同时写事实链条和刑法评价。
5. 追赃挽损部分要具体到财产、账户、证照、账册、印章或经营文件。
6. 对持续侵害要使用现在时表达，强调不法状态仍需制止。
7. 持续侵害报告应采用“危险正在发生 → 我方已经自救 → 自救仍然不足 → 请求机关阻断”的结构。
8. 涉及责令退赔时，要区分被告人获利金额和被害单位实际损失金额，必要时按民事损害赔偿规则重构退赔计算方法。

## 六、持续侵害制止型报告结构

```text
一、案件已进入刑事程序，但侵害仍在持续
二、持续侵害的具体路径和损害后果
三、被害单位已采取的应急措施
四、被害单位自救不足以阻断侵害
五、请求侦查机关采取具体措施
```

可请求措施包括：

- 收缴公章、证照、账册、合同
- 冻结账户和第三方收款通道
- 查封、扣押涉案财物
- 通知租户、客户或相关第三人
- 组织司法审计
- 制止现场占有、停水停电、换锁等侵害
- 追查继续实施侵害的人员

## 七、追诉遗漏犯罪事实报案结构

适用于已有刑事案件，但仍存在遗漏事实、遗漏罪名、遗漏嫌疑人、遗漏犯罪单位或遗漏追赃措施的场景。

```text
一、报案单位、报案人、犯罪嫌疑人和嫌疑单位
二、报案请求：追诉遗漏事实、追赃、查封扣押冻结
三、第一组遗漏事实：事实链、证据附件、罪名评价
四、第二组遗漏事实：事实链、证据附件、罪名评价
五、第三组遗漏事实：事实链、证据附件、罪名评价
六、持续侵害或公共秩序风险
七、总结请求
```

遗漏事实可按以下类型分组：

- 股权/公司控制权侵害
- 资金套取和虚构债务
- 房产或重大资产转移
- 关联公司作为犯罪载体
- 虚假诉讼、仲裁、执行
- 持续收租、强占物业、破坏经营
- 遗漏共同犯罪人或主管人员
- 遗漏犯罪单位

每组事实应尽量同时写明：

- 行为人
- 行为方式
- 财产后果
- 证据附件
- 拟评价罪名或追诉方向
- 与既有案件的关联

## 八、被害单位诉讼权利保障申诉结构

适用于被害单位或诉讼代理人已经向公安机关申请获取维权相关案件信息，但公安机关未依法送达、未告知、未提供资料，影响被害单位知情权、申请权、追赃挽损或经营接管的场景。

```text
一、申诉人和申诉事项
二、刑事案件基本进展
三、被害单位此前提出的具体资料申请
四、公安机关未送达、未告知或未提供资料的事实
五、该行为对被害单位维权和诉讼权利的影响
六、检察机关受理申诉控告和监督纠正的依据
七、请求检察院督促公安机关纠正
```

可请求公安提供或处理的事项包括：

- 送达本案相关法律文书
- 告知案件移送、退查、撤案等程序进展
- 提供与被害单位维权相关的强制措施证明
- 提供查封、扣押、冻结本单位财产的清单
- 返还或移交营业执照、公章、证照、账册、合同等经营资料
- 对被害单位或诉讼代理人的申请作出书面回复

表达上应避免泛化为“要求了解全部案情”，而应限定为“依法应送达、应告知、与被害单位维权相关”的资料。

## 九、被害人退赔损失核算结构

适用于起诉书、判决或侦查结论低估被害人损失，或赃物灭失、无法追缴，需要折价退赔的场景。

```text
一、刑事退赔兼具民事赔偿性质
二、起诉书/原认定对损失金额的核价方式错误
三、应采用的替代核价方法
四、替代核价方法的事实和证据依据
五、需要法院/检察院调取的关键证据
六、最终退赔金额、利息或孳息主张
七、具体请求
```

常见核价路径包括：

- 市场价格法
- 实际购买价法
- 鉴定/评估价法
- 市价折余法
- 收益损失法
- 已付款/已返还财物扣除法

此类文书必须做数值一致性复核，避免单价、数量、年限、残值、本金、利息和总额之间出现冲突。
