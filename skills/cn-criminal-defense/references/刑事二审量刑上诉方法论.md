# 刑事二审量刑上诉方法论

## 一、用途

本文件用于沉淀老师在刑事二审量刑上诉中的稳定方法。重点处理一审定罪基本不再作为主要突破口，但量刑情节、证据调取、法律适用和刑期目标仍有调整空间的案件。

## 二、基础工作流

```text
读取一审判决
→ 摘出一审不采纳辩护意见的理由
→ 判断哪些争点能实质改变刑期
→ 区分法定情节和酌定情节
→ 从事实证据不足和法律适用错误两端攻击
→ 设置主位、备位和量刑承接
→ 提出明确刑期目标
```

## 三、上诉争点选择

优先选择：

1. 自首、立功、坦白、认罪认罚等到案和供述情节。
2. 主从犯、胁从犯、帮助犯等共同犯罪地位。
3. 犯罪数额、既未遂、犯罪次数等影响量刑基础的事实。
4. 退赃退赔、谅解、主动补救等酌定情节。
5. 一审未调取或未评价的无罪、罪轻证据。

避免平均用力。二审上诉状应围绕最可能改变刑期的争点集中展开。

## 四、“以自首论”审查清单

1. 办案机关到案前掌握了什么线索？
2. 该线索是否有客观载体？
3. 该线索是确定犯罪事实，还是模糊怀疑？
4. 被告人主动供述了哪些机关尚未掌握的事实？
5. 已掌握线索与供述罪行是否同种罪行？
6. 若裁判机关主张“法律、事实上密切关联”，是否同时具备法律和事实关联？
7. 是否存在部分自首空间？
8. 即便不认定自首，能否作为酌定从宽情节评价？

## 五、从犯审查清单

1. 犯意由谁发起？
2. 犯罪目标由谁确定？
3. 犯罪对象和机会由谁控制？
4. 犯罪指标或任务由谁提出？
5. 具体实施由谁完成？
6. 赃款分配由谁决定？
7. 分赃比例是否足以否定从犯？
8. 被告人是否具有被动、辅助、执行性角色？

## 六、文书结构

二审量刑上诉状可采用：

```text
一、上诉请求
二、摘引一审判决不采纳辩护意见的理由
三、一审未认定某法定情节，事实证据不足、适用法律错误
四、一审未认定另一法定情节，事实证据不足、适用法律错误
五、量刑建议：将法定情节、酌定情节与刑期目标连接
六、结论：请求撤销或改判
```

## 七、表达规则

1. 二审文书要先锁定一审错误，不宜重新长篇铺陈全案事实。
2. 每项上诉理由都要对应一审判决的具体认定。
3. 对未调取证据，要说明证据内容、证明目的和对量刑的重大影响。
4. 对规范解释，应尽量引入存疑有利、罪责刑相统一、有利于被告人等二审可接受语言。
5. 必须设置备位主张，避免主位不成立时文书失去量刑承接。
6. 量刑建议要把法定情节和酌定情节合并说明，形成明确目标。
