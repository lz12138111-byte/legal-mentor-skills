# 涉黑案件四特征拆解与退查重移审查起诉方法论

## 一、适用场景

适用于组织、领导、参加黑社会性质组织罪，恶势力犯罪集团，或者多罪名团伙案件被拔高评价为涉黑涉恶的审查起诉阶段，尤其适用于一次或二次退回补充侦查后重新移送审查起诉。

## 二、总原则

涉黑案件的辩护不能只逐个罪名零散反驳，应当先处理整体评价。

```text
先去黑化
→ 再拆组织归责
→ 再拆下游个罪
→ 再拆程序和涉案财产
→ 最后处理强制措施
```

如果黑社会性质组织四特征不成立，下游犯罪即使部分成立，也可能只是普通犯罪、个别人员犯罪或经济纠纷衍生违法。

## 三、起诉意见书归责规则审查

涉黑案件首先审查起诉意见书是否把“组织犯罪责任”说清楚。

必须追问：

- 组织成立时间是什么。
- 组织者、领导者、积极参加者、一般参加者分别是谁。
- 每项犯罪是否代表组织意志。
- 每项犯罪是否使用组织名义。
- 每项犯罪是否维护组织利益。
- 同一组织的不同组织者、领导者被归责的罪名范围是否一致。
- 是否把个人犯罪、公司经营行为、经济纠纷、临时纠集行为泛化为组织犯罪。

输出表：

| 下游事实/罪名 | 实施人员 | 是否代表组织意志 | 是否使用组织名义 | 是否维护组织利益 | 是否应归责于组织 | 证据缺口 |
| --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |

## 四、四特征拆解

### 1. 组织特征

审查重点：

- 是否有稳定组织结构。
- 是否有明确组织者、领导者、骨干成员。
- 是否有层级、职责分工、纪律规约。
- 成员是否固定。
- 人员关系是犯罪组织成员，还是公司员工、临时雇佣人员、普通朋友或债务纠纷参与者。

常见攻击点：

- 人员松散、临时纠集。
- 无入伙形式、无规约、无纪律。
- 无控制属性和服从关系。
- 公司员工领取工资不等于被豢养。
- 临时劳务报酬不等于组织成员生活供养。

### 2. 经济特征

审查重点：

- 经济利益来源是违法犯罪，还是企业经营、合伙收益、租金、担保费、劳务收入。
- 收益是否归属于同一个组织。
- 是否由组织统一管理、统一支配。
- 是否用于实施违法犯罪、维系组织发展、豢养成员、寻求非法保护。

常见攻击点：

- 企业经营收益不等于黑社会性质组织经济利益。
- 多个公司独立法人、自支自理，不存在统一经济组织。
- 收入归属于股东、合伙人、公司，不归属于所谓黑社会组织。
- 支付工资、劳务费、业务提成不等于豢养成员。
- 公司亏损、负债、被执行，反而削弱“经济实力”认定。

### 3. 行为特征

审查重点：

- 是否有组织地多次实施违法犯罪。
- 是否以暴力、威胁为基本手段，且随时可能付诸实施。
- 是否为非作恶，欺压、残害群众。
- 下游犯罪是否具有事出有因、债务追偿、劳动纠纷、家庭纠纷、邻里纠纷等背景。

常见攻击点：

- 贷款诈骗、骗取贷款、拒执、非法侵入住宅、非国家工作人员受贿等不具有暴力或以暴力相威胁属性。
- 讨债引发的非法拘禁、故意伤害、寻衅滋事等，即使构成犯罪，也可能只是事出有因的一般犯罪。
- 对象特定、目的单一、围绕经济纠纷，不等于欺压不特定群众。
- 强迫交易若本质是债务追偿，应先审查权利基础和财产性犯罪阻却。

### 4. 非法控制特征

审查重点：

- 是否称霸一方。
- 是否在一定区域或者行业内形成非法控制或重大影响。
- 是否严重破坏经济、社会生活秩序。
- 是否使群众形成心理强制或者安全感下降。

常见攻击点：

- 作案地点分散。
- 侵害对象特定，多为债务人或交易相对方。
- 未形成行业垄断、市场排挤或区域控制。
- 犯罪目的不是争夺势力范围，而是追债或经济利益纠纷。
- 没有严重破坏当地经济、社会生活秩序的证据。

## 五、刑民交叉和权利救济切割

涉黑案件常把债务纠纷、担保追偿、公司经营、市场管理、民事执行冲突等事实刑事化。辩护时必须先还原民事权利基础。

审查顺序：

```text
是否存在合同/担保/借贷/合伙/劳动/公司治理关系
→ 是否有生效民事判决或执行案件
→ 是否产生债权、追偿权、自然之债或事实上的索赔基础
→ 行为是否围绕该权利基础发生
→ 手段违法是否应评价为普通犯罪，而非涉黑行为特征
```

稳定规则：

- 有债的前提下，追债通常具有权利救济目的。
- 权利救济不当然排除所有犯罪，但可以排除财产性犯罪或涉黑“为非作恶”评价。
- 如果手段行为构成故意伤害、非法拘禁等非财产犯罪，应按个罪评价，避免拔高为涉黑。

## 六、权利救济证据底座

权利救济不能只写成抽象法理，必须证据化。涉黑讨债类案件尤其要把“为什么是讨债，而不是无因作恶”说清楚。

### 1. 民事诉讼和执行案件链

| 民事案号/执行案号 | 原告/申请执行人 | 被告/被执行人 | 本刑案对应被害人 | 判决确定债务 | 担保责任 | 追偿权基础 | 备注 |
| --- | --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |  |

审查目的：

- 证明刑案被害人与嫌疑人或关联公司之间并非陌生关系。
- 证明双方存在贷款、担保、追偿、执行等前置民事法律关系。
- 证明所谓强迫交易、寻衅滋事、非法拘禁等下游行为存在事出有因背景。

### 2. 合同权利链

| 合同/文件 | 当事人 | 核心权利义务 | 对应标的物/金额 | 与刑案事实的连接 | 证明目的 |
| --- | --- | --- | --- | --- | --- |
| 保证担保服务及反担保合同 |  |  |  |  |  |
| 保管合同 |  |  |  |  |  |
| 质押物清单/移交清单 |  |  |  |  |  |
| 以物抵债合同 |  |  |  |  |  |
| 生产管理承包合同 |  |  |  |  |  |

审查目的：

- 证明取得、移动、监管、处置家具设备等行为是否存在合同基础。
- 证明所谓“低价取得财物”是否可能是质押、抵债或保管关系。
- 证明被害人是否曾经确认质押物、抵债物、保管义务或费用支付。

### 3. 被害人与债务关系对应表

| 刑案被害人 | 指控事实 | 对应民事案件 | 对应合同/清单 | 债务或担保关系 | 辩方用途 |
| --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |

审查目的：

- 避免笼统说“被害人均有债务关系”。
- 把每个被害人对应到具体民事案件和合同。
- 让检察机关能够逐项核查权利救济事实。

## 七、贷款诈骗和骗取贷款的拆解

贷款类事实必须逐笔审查，不能让起诉意见书用总额和结果替代构成要件。

逐笔审查表：

| 贷款编号 | 贷款申请人 | 担保人 | 银行 | 金额 | 合同时间 | 欺骗方式 | 资金用途 | 还款情况 | 未还原因 | 与嫌疑人关系 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |  |  |  |  |

攻击规则：

- 未还贷结果不能反推非法占有目的。
- 贷新还旧、持续还款、多方筹资，通常可以反证非法占有目的。
- 担保人提供担保本身降低银行风险，不当然具有骗贷动机。
- 担保人若构成犯罪，应审查其是实行犯还是帮助犯，并遵守共犯从属性。
- 生效民事判决已确认贷款担保关系时，刑事指控不得随意否定既判法律关系。

## 八、拒执罪的刑民执行交叉拆解

拒不执行判决、裁定罪不能只看“有判决未履行”，必须先审查执行主体和执行财产。

| 生效裁判 | 被执行人 | 裁判义务 | 嫌疑人是否为被执行人 | 指控财产 | 财产权利人 | 是否属于执行财产 | 证据缺口 |
| --- | --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |  |

稳定规则：

- 非被执行人原则上不负执行义务。
- 独立法人财产不能直接等同于自然人财产。
- 仓库前身、关联关系、实际影响力，不能当然证明财产混同。
- 拒执罪必须同时证明有执行义务、有执行能力、有拒不执行行为。

## 九、诈骗罪与民事欺诈切割

涉黑案件中的收费、居间、担保、委托代办贷款等事实，容易被刑事化为诈骗。必须审查受骗处分财产。

审查表：

| 指控事实 | 收费名目 | 相对人是否明知交易结构 | 是否取得交易目的 | 是否基于受骗处分财产 | 是否只是民事争议 |
| --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |

稳定规则：

- 民事欺诈与刑事诈骗都有“虚构事实”外观，但诈骗罪要求受骗者基于错误认识处分财产。
- 如果相对人明知交易结构变化仍继续付款，应慎重认定诈骗。
- 如果委托代办贷款的最终目的已经实现，后续费用争议更接近民事交易评价。

## 十、涉案财产审查

涉黑案件常伴随大规模查封、扣押、冻结。辩护人应同步制作涉案财产审查表。

| 财产名称 | 登记权利人 | 实际占有人 | 财产性质 | 与案件关系 | 查封/扣押/冻结依据 | 异议理由 | 处理请求 |
| --- | --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |  |

重点区分：

- 违法所得与合法财产
- 本人财产与家属财产
- 自然人财产与公司财产
- 公司经营资料与犯罪工具
- 第三人寄售、托管、共有财产
- 涉案财产与无关财产

## 十一、退查重移阶段的写法

退查重移阶段的重点不是重复第一次意见，而是强调：

- 退查后哪些问题仍未查明。
- 哪些事实仍缺少明确性。
- 哪些无罪、罪轻证据仍未收集。
- 哪些嫌疑人辩解仍未核实。
- 哪些涉案财产仍未甄别。
- 检察机关应如何二次把关。

可用表达：

- “经一次退查，仍未查明……”
- “起诉意见书对该事实仍缺乏主体、时间、对象、后果等基本要素。”
- “该无罪辩解已有书证、证人证言相互印证，但未获有效核实。”
- “特促请贵院依法履行审查起诉和法律监督职责。”
- “先前意见不一致的，以本补充意见为准。”

二退重移阶段尤其适合用补充意见重新校准主线，将最有证据支撑的抗辩事实推到文书前部。

## 十二、同案修订版的简版结构

同一涉黑案件如果已经形成完整法律意见，后续脱敏版、压缩版或者再次沟通版，可以不重复展开全部事实，而是保留以下七段骨架：

```text
一、起诉意见书指控犯罪违反法律适用规则
二、黑社会性质组织的行为特征不成立
三、黑社会性质组织的经济特征不成立
四、黑社会性质组织的组织特征不成立
五、黑社会性质组织的非法控制特征不成立
六、重点个罪不成立，尤其是贷款诈骗罪、骗取贷款罪
七、程序问题、涉案财产问题、强制措施问题
```

这个简版结构的作用不是替代完整意见，而是在审查起诉沟通中提高表达效率：让办案机关先看到案件的法律评价错误，再看到四特征的系统缺口，最后看到个罪、财产和强制措施的具体处理请求。

## 十三、输出结构模板

```text
一、起诉意见书指控犯罪违反法律适用规则
（一）组织犯罪归责范围不一致
（二）犯罪事实缺乏明确性
（三）权利救济性质未被审查

二、关于行为特征
三、关于经济特征
四、关于组织特征
五、关于非法控制特征
六、关于重点个罪
七、关于刑事程序和涉案财产
八、关于强制措施
```

补充法律意见结构：

```text
一、先证明权利救济事实
二、再回到涉黑四特征
三、拆重点个罪
四、处理涉案财产和程序监督
五、附法律、司法解释，便于检察机关检索
```

## 十四、进入 skill 的稳定规则

1. 涉黑案件优先生成四特征拆解表，不先写普通辩护词。
2. 每个下游犯罪都要判断是否代表组织意志、使用组织名义、维护组织利益。
3. 对经济纠纷衍生犯罪，必须先还原民事权利基础。
4. 贷款类犯罪必须逐笔拆解，不接受总额式、结果式指控。
5. 企业经营收益必须审查归属、用途和统一支配，不能直接等同于涉黑经济基础。
6. 涉案财产必须单独成表，推动检察机关履行审查甄别职责。
7. 退查重移阶段要突出“退查后仍未补强”的问题。
8. 权利救济抗辩必须形成民事案件链、合同权利链、被害人对应表，不能停留在抽象法理。
9. 二退重移补充意见可明确“先前意见不一致的，以本补充意见为准”，用以重置辩护主线。
