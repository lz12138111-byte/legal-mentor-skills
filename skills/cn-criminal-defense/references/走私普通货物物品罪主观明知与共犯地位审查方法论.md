# 走私普通货物、物品罪主观明知与共犯地位审查方法论

## 一、适用场景

适用于运输司机、揽货人、仓储人员、物流中介等被指控参与走私普通货物、物品罪的案件，尤其适用于行为人没有直接参与境外采购、绕越非设关地或船舶运输，仅在货物入境后接收、派单和转运的情形。

## 二、核心判断公式

```text
走私实行行为发生时点
→ 被告人加入行为链条的时点
→ 是否存在事前或事中共同走私故意
→ 是否明知逃避海关监管并故意提供帮助
→ 运输行为是共同走私帮助还是事后转运/隐匿
→ 具体货物、货主和偷逃税款是否闭环
```

## 三、第一步：制作走私行为时间轴

| 阶段 | 行为 | 关键证据 |
| --- | --- | --- |
| 境外采购 | 货主购买、集货 | 采购记录、聊天、仓库记录 |
| 绕关进境 | 逃避海关监管 | 船只、码头、定位、通信、查扣记录 |
| 境内接收 | 接货、验货、分拨 | 司机供述、物流单、监控、电话 |
| 国内转运 | 送货、转运给货主 | 派单、运输费、货拉拉、收货记录 |
| 查扣计税 | 货物查扣、估价、核税 | 清单、鉴定/计核报告、税款计算表 |

不要先问“司机运的是不是走私货”，应先问“其运输行为发生在走私既遂之前还是之后，以及运输是否在前置走私故意支配下已经被安排”。

## 四、第二步：通谋与主观明知审查

### 1. 明知的层级

分别审查：

1. 是否知道货物来自境外；
2. 是否知道货物未经正常报关；
3. 是否知道货物属于逃避海关监管的非法进境货物；
4. 是否在知道上述事实后仍希望或放任走私结果；
5. 是否在绕关前或绕关过程中提供了运输等帮助。

知道来自香港、猜测货物可能是走私、明确知道货物系逃避海关监管的走私货物，证明强度不同，不能概括处理。

### 2. 间接证据五项审查

| 审查项 | 要求 |
| --- | --- |
| 证据真实 | 供述、通信、定位、物流和查扣材料来源合法真实 |
| 相互印证 | 不同证据之间不存在关键矛盾 |
| 链条完整 | 从知道来源到提供帮助之间不存在断点 |
| 结论唯一 | 不能同时合理解释为普通物流、事后转运或被蒙骗 |
| 推理合理 | 经验法则必须与具体报价、包装、通信和行为反应相吻合 |

多次运输、异常包装、低价、境外来源、删除记录等可以构成推断材料，但每一项都要说明它证明的是“应当知道”“实际知道”还是“共同故意”，不能一步跳到有罪结论。

## 五、第三步：运输环节的角色判断

### 主位无罪

如果行为人是在货物已经完成非法进境后才被临时找来运输，且此前不知道货物性质、没有参与绕关安排、没有与走私团伙形成共同故意，应争取不构成走私共犯，并根据具体事实审查是否涉及其他罪名。

### 备位从犯

即使认定其在走私链条中提供运输帮助，也应核对：

- 是否决定绕关路线和进境方式；
- 是否控制货源、船只、仓库和货主；
- 是否决定货物价格和偷逃税款；
- 是否只是按固定运输费接单；
- 是否通过组织司机、派单和转运取得走私利润；
- 对前置走私行为的控制力和不可替代程度。

“没有亲自驾船绕关”不能自动等于从犯；“运输司机头目”也不能自动等于主犯，必须回到共同犯罪中的作用大小和控制程度。

## 六、第四步：税款金额闭环

```text
具体货主
→ 具体批次
→ 具体货物和数量
→ 进境方式
→ 价格及税率
→ 计核报告
→ 被告人对该批次的参与证据
```

对起诉意见书中的税款总额逐项核对：是否有计核报告、计税基础、货物清单、查扣对应关系和参与行为证据。没有具体货物计核和对应证据的金额，不应直接归入被告人涉案数额。

## 七、进入 skill 的稳定规则

1. 走私案件先输出行为时间轴，再输出主观明知和共犯地位分析。
2. 将“境外来源、未报关、走私性质、参与时点、帮助故意”分成五个独立问题。
3. 对封闭纸箱、气味、声音、司机猜测等间接证据，逐项审查其是否足以排除普通物流和被蒙骗解释。
4. 从犯意见必须有控制力、组织力、获利方式和不可替代性证据支撑。
5. 偷逃税款不能使用总额概括，必须形成货主、批次、货物、计核、参与证据闭环。
6. 主位无罪、备位从犯、金额扣减和认罪认罚应按层级表达，避免把相互冲突的事实结论混写。
