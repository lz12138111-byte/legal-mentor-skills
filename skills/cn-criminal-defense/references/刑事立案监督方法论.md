# 刑事立案监督方法论

## 一、用途

本文件用于沉淀老师在公安机关“不应当立案而立案”时，代表被立案人、近亲属、利害关系人向检察院申请刑事立案监督的方法。

该方法尤其适用于民事执行、公司控制权、公章证照、股东纠纷等事项被刑事化，或案件事实基础已经发生重大变化但公安机关仍拒不撤案的场景。

## 二、基础工作流

```text
确认公安已立案事实和罪名
→ 还原原始民事、执行或权利基础
→ 找出立案基础发生变化或原本不成立的事实
→ 从构成要件、正当理由、违法性/责任阻却角度否定犯罪成立
→ 证明当事人已经向公安申请撤案或纠正
→ 说明公安未撤案、未回复或指向检察院路径
→ 请求检察院对不应立案而立案进行监督
```

## 三、核心审查清单

### 1. 公安立案基础

- 公安以什么罪名立案？
- 原控告事实、移送事实或执行事实是什么？
- 是否采取了网逃、拘留、取保、查封冻结等措施？
- 立案机关是否仍掌握撤案或解除措施职责？

### 2. 不应立案的理由

- 行为是否不符合犯罪构成要件？
- 是否缺乏主观故意或非法占有目的？
- 是否存在紧急避险、自助行为、正当业务行为、权利冲突等正当化理由？
- 原民事、执行或行政基础是否已经撤销、终结、履行完毕或发生重大变化？
- 继续追诉是否已经没有现实必要性和法律正当性？

### 3. 前置救济

- 是否已经向公安提交撤案申请？
- 公安是否长期不处理、不回复？
- 是否有不受理信访事项告知书、口头告知、书面回复等材料？
- 是否已同步申请解除网逃、解除强制措施或终结执行？

### 4. 检察监督抓手

- 当事人是否属于可向检察院提出申请的主体？
- 请求是否明确指向“不应当立案而立案”的监督审查？
- 是否请求检察院通知公安机关纠正或撤案？
- 是否需要附上原执行材料、撤销执行申请、履行证明、公安不回复材料等附件？

## 四、文书结构

```text
一、申请人和申请事项
二、公安立案的原始事实和程序状态
三、后续查明或发生的新事实
四、为什么原行为不应被评价为犯罪
五、为什么继续立案没有法律正当性和现实必要性
六、公安拒不撤案、未回复或指向检察院路径
七、检察院立案监督依据
八、具体请求
```

## 五、表达规则

1. 标题应直接使用“立案监督申请书”，避免写成普通信访材料。
2. 申请事项要写成“请求对不应当立案而立案作出检察监督措施”。
3. 事实部分要先还原公安为什么立案，再说明为什么该基础已不存在或不成立。
4. 对拒执罪等执行衍生案件，应同步分析执行义务、义务履行、申请执行人态度、执行程序是否应终结。
5. 不只说“公安不撤案”，要说明“为什么这个案件不应继续作为刑事案件存在”。
6. 结尾请求要具体到受理审查、监督撤案、纠正错误立案、解除相关措施。

## 六、拒执罪错误立案专项框架

```text
原执行依据确定了什么义务
→ 被执行人为何没有履行
→ 未履行是否有紧急避险、权利冲突或其他正当理由
→ 义务后来是否已经履行
→ 申请执行人是否撤销执行或认可履行
→ 执行程序是否应终结
→ 继续以拒执罪立案是否仍有必要
→ 请求检察院监督公安撤案
```

## 七、与相邻文书的关系

```text
公安履职督促：强调公安不处理、不回复，应履行撤案或解除措施职责。
法院执行监督：解决执行程序本身是否应终结、执行措施是否应解除。
拒执罪撤案共同意见：直接提交公安，由被立案人一方和申请执行人/被害单位一方共同请求撤案。
刑事立案监督：请求检察院审查公安是否不应当立案而立案。
诉讼权利保障申诉：解决被害单位或代理人拿不到案件信息的问题。
```

同一案件中可以组合使用，但每份文书必须只打一个主要程序目标。
