# 受贿罪职务行为与劳务报酬性质审查方法论

## 一、适用场景

适用于国家工作人员收取咨询费、技术服务费、代理费、中介费、借款本息、节日红包或合作收益，被控方概括评价为受贿的案件。

## 二、核心判断公式

```text
收款事实
→ 款项的民事或业务基础
→ 对方是否有具体请托事项
→ 请托事项是否受行为人职务制约
→ 行为人实施的是公务行为还是私人劳务
→ 款项是否是职务交换对价
→ 是否构成受贿罪
```

受贿罪的审查重点不是“有没有收钱”，而是“钱是否购买了具体的公务性职务行为”。

## 三、第一步：制作五栏职务关联表

| 审查项 | 关键问题 |
| --- | --- |
| 职务权限 | 行为人所在机关和具体岗位依法能决定、审批或影响什么 |
| 请托事项 | 对方希望行为人实际完成什么 |
| 权力制约 | 行为人能否决定、批准、否决、加速或阻止该事项 |
| 实际行为 | 行为人实施的是公务活动、技术指导、中介服务还是私人交往 |
| 利益结果 | 对方是否因职务行为获利，还是只获得一般劳务或信息服务 |

只有在职务权限与请托利益之间存在现实制约关系时，才具备权钱交易的基本结构。

## 四、第二步：公务职务行为与私人专业劳务区分

| 公务职务行为 | 私人专业劳务 |
| --- | --- |
| 依职权审核、批准、评审、监管、处罚 | 依据个人知识、技术、经验提供指导或咨询 |
| 能直接改变行政相对人的权利义务 | 只能提供建议、方案或资源介绍 |
| 行为结果归属于机关和岗位职责 | 行为成果属于个人服务合同履行 |
| 存在公权力制约和利益交换 | 存在服务内容、履行记录和合同对价 |

审查时要问：如果行为人不具有该行政职务，仅凭其专业能力和行业经验，是否仍然能够提供相同服务？如果答案是肯定的，应重点审查该收入是否属于私人劳务报酬。

## 五、第三步：合同劳务报酬审查

“有合同”不是当然无罪，“公务人员违法兼职”也不是当然受贿。应分两层：

### 1. 合同真实与实际履行

- 服务内容是否具体；
- 服务周期、对象和交付标准是否明确；
- 是否存在现场指导、技术建议、方案设计、资源对接等客观履行；
- 是否有委托方、员工、合作方证言和工作记录相互印证；
- 报酬是否与服务难度、周期、专业稀缺性相适应。

### 2. 服务内容与职务权限是否交叉

- 合同是否直接约定影响审批、评审、许可、监管或行政奖励；
- 行为人所在机关是否具有相应决定权；
- 请托事项是否已经进入行政程序；
- 行为人能否单独或实质性影响结果；
- 所提供的专业意见是否只是工程、技术、管理或行业经验。

## 六、第四步：预支款、借款和已返还款审查

对大额款项不能一概认定为受贿，应建立款项时间表：

| 问题 | 证据 |
| --- | --- |
| 谁提出借款或预支 | 证言、聊天记录 |
| 是否有借条、还款承诺 | 借条、合同、微信 |
| 是否实际提供本金或服务 | 银行流水、现场记录 |
| 是否催还、归还 | 催款信息、还款流水 |
| 返还发生在何时 | 时间节点、办案前后 |
| 剩余款项如何结算 | 合同履行、对账、尾款记录 |

“有借有还”、合同预支、劳务垫付款与受贿款在所有权转移、返还义务和交易结构上不同。已经返还的款项还应审查是否影响受贿金额、违法所得和量刑评价。

## 七、第五步：中介费和生效民事裁判

中介费审查重点：

- 是否存在真实委托找址、介绍资源或促成交易的服务；
- 中介事项是否与行为人的公务职务分离；
- 中介费是否由市场价格、服务难度和交易规模支持；
- 是否有生效民事判决确认委托关系、付款基础或返还责任；
- 民事裁判确认的事实与刑事案件的职务关联是否相同。

生效民事判决可以作为重构款项民事基础的重要证据，但不能自动替代对受贿构成要件的审查。

## 八、第六步：过节费、礼金与感情投资

应逐项核对：

1. 送受双方是否存在上下级、行政管理或业务管理关系；
2. 是否存在具体请托事项或实际、承诺的利益；
3. 行为人是否基于既往履职收款；
4. 金额、时间、次数和累计数额；
5. 是否存在回礼、朋友关系和社会交往背景；
6. 案件行为发生时适用哪一版本的司法解释和定罪规则。

不得只凭“节日收红包”或“金额较多”作结论，必须把请托、职务行为、利益结果和规范时间对应起来。

## 九、审查起诉阶段的三层输出

```text
主位：劳务报酬、中介费、借款、合伙收益或礼尚往来不宜认定为受贿
次位：预支款、已返还款、无职务关联款项应从受贿数额中扣除
量刑位：如实供述、主动交代未掌握事实、退赃、初犯、未谋取非法利益和社会贡献
```

文书可以承认部分不规范或纪律违规，但必须明确：行政纪律责任、民事返还责任与刑事受贿责任的构成基础不同。

## 十、进入 skill 的稳定规则

1. 收款型受贿案件先生成“职务权限—请托事项—实际行为—利益结果—收款性质”五栏表。
2. 有合同不当然排除受贿，无合同也不当然证明受贿，必须审查真实履行和职务交叉。
3. 能否影响评审、审批、许可、监管或行政奖励，是判断职务关联性的核心事实。
4. 专业技术指导、中介找址、行业资源介绍和私人咨询，应与公务职权逐项切割。
5. 借款、预支、已返还款和合同尾款应逐笔核算，不能整体定性或重复计算。
6. 节日礼金和感情投资必须查明具体请托、职务行为、关系、金额累计和适用规范。
7. 生效民事判决可用于固定民事关系和款项基础，但不能单独决定刑事定性。
8. 正式文书使用具体数额标准、司法解释和“从旧兼从轻”时，必须按行为时间动态核对。
