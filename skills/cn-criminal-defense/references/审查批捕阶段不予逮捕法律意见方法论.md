# 审查批捕阶段不予逮捕法律意见方法论

## 一、适用场景

适用于公安机关提请批准逮捕后，辩护人向检察机关提交不予逮捕法律意见，争取：

- 犯罪事实不清、证据不足，不批准逮捕。
- 罪名适用存在重大争议，不批准逮捕。
- 侦查机关未全面收集或移交无罪证据，不批准逮捕并监督侦查。
- 即便涉嫌犯罪，也无社会危险性或无逮捕必要。

## 二、核心原则

不予逮捕意见不要只写“无社会危险性”。应先审逮捕的事实和证据基础。

```text
是否构成犯罪
→ 是否有充分证据证明构成要件
→ 是否存在无罪证据未收集、未移交
→ 是否需要检察机关履行侦查监督
→ 是否仍有逮捕必要性
```

如果犯罪事实本身存在合理怀疑，逮捕必要性不是主战场。

## 三、第一步：罪名边界审查

当案件涉及行政违法和刑事犯罪边界时，应先审查入罪边界。

| 审查项 | 追问 |
| --- | --- |
| 概念来源 | 控方使用的概念来自法律、司法解释，还是部门批复、行政规范 |
| 入罪依据 | 该依据是否可作为刑事定罪依据 |
| 解释方向 | 是否存在扩大解释、类推解释风险 |
| 刑法谦抑 | 是否可以行政处罚、行业监管、治安处罚解决 |
| 罪刑法定 | 刑法是否明确规定该行为入罪 |

稳定表达：

- 行政违法不等同于刑事犯罪。
- 行政处罚依据不能当然作为刑事定罪依据。
- 刑法解释应严格遵守罪刑法定原则和谦抑性原则。

## 四、第二步：构成要件证据表

批捕阶段也要做构成要件表，只是表达比庭审更聚焦“是否足以逮捕”。

| 构成要件 | 控方证据 | 辩方疑点 | 是否达到批捕条件 |
| --- | --- | --- | --- |
| 主体 |  | 是否仅以身份推定 |  |
| 主观故意 |  | 是否有反向合规证据 |  |
| 客观行为 |  | 行为是否具体、是否相互印证 |  |
| 法益侵害 |  | 是否只是名义侵害或行政违法 |  |
| 组织/控制行为 |  | 是否有管理控制、收益控制、人身控制 |  |

## 五、第三步：无罪证据和反向证据

不捕意见必须主动展示无罪证据，而不只是说控方证据不足。

常见反向证据：

- 合同、制度、员工守则。
- 微信群通知、会议纪要、签名确认。
- 巡查记录、处罚记录、整改记录。
- 财务分配记录，证明未控制违法收益。
- 证人证言，证明嫌疑人未参与、未明知、未放任。

写法：

```text
该证据能够证明嫌疑人主观上排斥违法结果，
客观上履行管理、监督或合规职责，
与组织、策划、指挥违法犯罪活动的指控方向相反。
```

## 六、第四步：侦查程序和检察监督

如果侦查机关扣押无罪证据但未随案移交，应在不捕意见中明确提出。

审查表：

| 证据名称 | 证明目的 | 是否被扣押 | 是否有扣押清单 | 是否随案移交 | 请求 |
| --- | --- | --- | --- | --- | --- |
| 劳动协议 | 禁止违法服务 | 是/否 | 是/否 | 是/否 | 核查并调取 |
| 会议纪要 | 履行合规管理职责 | 是/否 | 是/否 | 是/否 | 核查并调取 |
| 聊天记录 | 曾经警示、制止违法 | 是/否 | 是/否 | 是/否 | 提取并审查 |

稳定表达：

- 侦查机关高度关注有罪事实，却明显忽视无罪证据。
- 无罪证据未随案移交，导致逮捕审查基础不完整。
- 特促请检察机关依法履行法律监督职责。

## 七、第五步：逮捕必要性兜底

如果犯罪事实争议较大，但检察机关暂不接受无罪观点，可以继续写逮捕必要性。

可写因素：

- 无前科劣迹。
- 有固定住所、工作、家庭。
- 主动配合调查。
- 证据已经固定，无串供、毁证可能。
- 涉案行为边界模糊，主观恶性较低。
- 可通过取保候审保障诉讼。

注意：本类文书不要一开始就写这些，否则会弱化主位无罪观点。

## 八、非国家工作人员受贿罪的职务便利与收款性质审查

审查非国家工作人员受贿罪时，应先围绕权钱交易建立四段证明链：

```text
职务身份
→ 具体职务权限
→ 为他人实施或承诺实施职务行为
→ 对方基于该职务行为交付财物
```

重点审查：

- 收款是否可能属于借贷本息、合伙收益、居间费、代购报销或其他业务收入；
- 行为人是否具有供应商导入、价格、份额、拨款等事项的启动权、否决权、修改权或最终批准权；
- 参与审核、评审、投票、签字和传递文件，是否只是建议权、审核权或程序性工作便利；
- “经手权”所指向的是否是财物或交易结果本身，行为人是否具有直接控制和独立支配权；
- 收款时间、频率、金额和用途是否与具体采购节点、采购结果和职务行为对应。

采购流程应拆成启动、供应商导入、价格审批、份额分配等节点，逐项标注实际决定人、共同参与人、最终批准人和嫌疑人能够施加的影响，避免用“采购人员”身份替代独立支配权证明。

对借贷本息、合伙收益和居间费，应分别核对实际出资、借条、流水、还款规律、共同经营、物料范围、公司业务关联和合作形成时间。支付模式可以提出合理替代解释，但必须与制度、流水、合同、聊天和业务记录相互印证。

## 九、投资合伙型诈骗案件的民刑切割

当案件涉及网店投资、共同经营、情侣转账、个人账户收款和经营亏损时，应先建立双方民事法律关系，再审查诈骗罪的非法占有目的。

审查顺序：

```text
是否存在真实经营主体
→ 双方是否共同经营、共享收益、共担风险
→ 投资人是否参与决策、控制账户和监督资金
→ 收款是否用于采购、工资、租金、推广和其他经营成本
→ 是否存在分红、返款、指定支付和继续借款经营
→ 是否能证明收款时即有非法占有目的
```

重点规则：

- 投资人交付款项不当然等于被诈骗交付，可能属于合伙出资、借款、赠与、委托费用或其他民事给付。
- 个人名义开设账户不当然等于个人占有，应结合网店主体、供应商、员工、运营群、经营数据和资金流向判断财产性质。
- 真实经营、部分分红、按投资人指示付款、未使用费用返还、经营亏损后继续借款维持业务，均可反证收款时的履约意愿。
- 投资人掌握账号、员工、供应商和经营数据时，可以证明其参与经营并仍具有查账、清算、追偿和分担亏损的民事救济路径。
- 情侣关系中的已完成赠与，应与合伙投资款逐笔区分，不能用关系标签混同全部款项。

## 十、诈骗案件的事后行为与初始故意审查

诈骗案件应制作四节点时间轴：

```text
财产交付前
→ 财产交付后履约
→ 项目争议后行为
→ 争议解决和补救行为
```

审查重点：

- 事后伪造、补签、解释或承诺不能机械倒推收款时已经具有非法占有目的，但应单独排查是否形成新的犯罪或违法风险。
- 平台活动、补贴、项目机会在交付时尚未确定的，应审查被害人是否明知不确定性、是否仍然自愿委托，以及双方是否共同承担商业风险。
- 实际履约、部分成果、转委托、运营成本、退款、还款计划和诉讼方案，可以用于证明履约意愿和民事救济路径，但不能单独替代对欺骗行为、错误认识、财产处分和非法占有目的的审查。
- 事后补救行为应与初始收款时的主观状态分开评价，避免结果倒推。

自首和到案过程应另行核验：被害人通知到场、明知可能报警、到场后被公安抓获，并不当然等于自动投案，必须核对公安掌握程度、到场控制方式和行为人的主动性、自愿性。

## 十一、羁押地点异常与辩护权监督

不捕申请中发现家属未收到拘留通知书、通知书载明地点与实际羁押地点不一致、看守所否认羁押、承办人员拒绝告知等情况时，应按以下结构整理：

```text
具体日期和机关行为
→ 家属无法确认羁押地点
→ 律师会见受阻或延误
→ 嫌疑人接受辩护和程序救济的权利受影响
→ 请求检察机关调查、纠正并履行侦查监督职责
```

程序问题不能只作为情绪性控诉，应说明其如何影响家属知情权、律师会见权、辩护权和批捕审查的完整性。

## 十二、文书结构模板

```text
一、案涉行为是否属于刑法意义上的犯罪行为，存在重大争议
（一）行政违法概念不能当然作为刑事定罪依据
（二）刑法解释应遵守罪刑法定和谦抑性原则

二、认定嫌疑人实施犯罪，缺乏充分证据证明
（一）关键客观行为事实未得到相互印证
（二）不能仅以身份、职务或场所地位推定犯罪
（三）反向证据证明嫌疑人无犯罪故意和犯罪行为

三、侦查程序未充分贯彻全面收集有罪、无罪证据的要求
（一）无罪证据未被重视
（二）嫌疑人辩解未被有效核实
（三）扣押无罪证据未出具清单、未随案移交

四、即便暂不采纳无罪意见，亦无逮捕必要性

综上，请求贵院依法对嫌疑人作出不予批准逮捕决定。
```

## 十三、进入 skill 的稳定规则

1. 用户输入不予逮捕、不捕、审查批捕、提请批捕等关键词时，应优先调用本方法。
2. 不捕意见先审犯罪事实和证据条件，再审社会危险性。
3. 行政违法和刑事犯罪边界模糊时，应单独制作入罪边界审查。
4. 有无罪证据未移交时，应请求检察机关核查、调取并履行法律监督职责。
5. 逮捕必要性作为兜底，不要冲淡主位无罪或证据不足意见。
6. 投资、合伙、网店经营型诈骗案件，必须先做民事法律关系矩阵和资金用途表。
7. 羁押地点、拘留通知和律师会见存在异常时，应同步提出事实调查和检察监督请求。
8. 非国家工作人员受贿案件必须制作“职务权限—采购流程—收款性质—职权关联性”四栏表，并保留数额和法律适用兜底。
9. 诈骗不捕案件应制作四节点时间轴，区分事后不当行为与初始收款故意。
10. 自首主张必须核对具体到案经过，不能仅凭“明知可能报警而到场”直接认定自动投案。
