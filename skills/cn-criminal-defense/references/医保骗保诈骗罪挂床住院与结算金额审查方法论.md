# 医保骗保诈骗罪挂床住院与结算金额审查方法论

## 一、适用场景

适用于医疗机构、医保负责人、医生、护士、财务或资料上传人员被指控通过挂床住院、伪造病历、虚增耗材价格、虚开发票或虚假申报骗取医保基金的案件。

核心边界是：医保协议或行政处理中的违规，不当然等于刑法上的诈骗；医院内部存在骗保行为，也不当然证明每一名管理、审核或上传人员具有共同诈骗故意。

## 二、核心判断公式

```text
医保协议具体违规标准
→ 患者级别事实核查
→ 病历/费用/申报行为是否虚假
→ 被告人实际职权、信息来源和控制能力
→ 是否存在指使、共谋、明知或放任
→ 医保基金实际损失和金额闭环
→ 罪名、责任层级和不起诉/取保路径
```

## 三、第一步：挂床住院的行政规则与刑事事实分开

患者不在床、离院或没有过夜，只是事实线索，不是当然的刑事结论。应根据适用年度医保协议逐案核对：

- 是否属于门诊治疗办理住院；
- 是否仍在上班；
- 是否连续两日以上无医疗费用或诊疗记录；
- 是否无床位、同床多人或病区无合格医护人员；
- 是否被查实两次不在院；
- 是否无住院病历、床位号不一致；
- 是否属于日间手术、中医日间病房等协议排除情形。

制作患者级别表：

| 患者 | 住院手续 | 诊疗事实 | 离院/请假 | 病历护理 | 费用记录 | 协议条款 | 最终结论 |
| --- | --- | --- | --- | --- | --- | --- | --- |

患者单方事后陈述、个别查房时点和群聊摘录，应与医嘱、手术、输液、换药、护理和费用资料相互印证。

## 四、第二步：病历伪造和上传行为的责任分层

医院骗保案件应将人员分为：

1. 组织经营和制定业绩任务的人；
2. 要求修改、完善或制作病历的人；
3. 具体实施诊疗、填写和归档病历的人；
4. 掌握财务、采购、发票和资金分配的人；
5. 负责医保审核、上传或结算的人。

对每名被告人分别审查：

| 要素 | 问题 |
| --- | --- |
| 职权 | 是否有日常经营、人事、财务和医生管理权 |
| 信息 | 是否知道患者真实在院和诊疗情况 |
| 行为 | 是否指使、修改、制作、审核、上传或仅履行技术流程 |
| 主观 | 是否明知、希望或放任骗取医保基金 |
| 获利 | 是否分红、提成、提高业绩或取得额外利益 |
| 反向行为 | 是否培训合规、要求真实记录、退费、停止上传或提出异议 |

上传行为本身不等于诈骗实行行为；但如果证据证明上传人员明知虚假并故意帮助结算，仍可能构成共同犯罪或帮助行为。关键在于信息来源、审核能力和主观认识。

## 五、第三步：信息壁垒、期待可能性与可责性

当被告人主张其不知患者真实情况时，应核查：

- 医院管理人员是否掌握真实住院名单并拒绝提供；
- 被告人是否有权限查看病历、护理、费用和住院管理系统；
- 上传前是否有制度要求逐一电话核实；
- 医保批量结算是否允许由专人基于形式材料上传；
- 被告人是否曾因投诉、抽查或异常数据发现问题；
- 发现问题后是否采取停止上传、退费、整改、培训或报告措施。

“没有能力控制”与“没有信息来源”是事实命题，“缺乏期待可能性”是责任评价。两者必须分别举证，不能只以职务名称或形式授权推定其应当知道全部虚假事实。

## 六、第四步：医保诈骗金额四层核算

不能将结算单上的“基金支付合计金额”直接等同于诈骗数额。至少拆成：

```text
结算单申报/记账金额
− 真实诊疗的合法费用
− 审核扣减、月度预结算和年度清算调整
− 行政追回和医院退款
= 可能具有刑法评价意义的实际损失
```

需要调取和核对：

1. 每名患者的病历、医嘱、护理、治疗和费用明细；
2. 每名患者的挂床天数及床位、护理、治疗项目；
3. 医保机构月度预结算、审核扣减、年度清算和实际拨款；
4. 行政处罚、基金追回和医院退款清单；
5. 控方金额表与上述材料的逐笔对应关系。

### 非整数天数

以“0.5天”“1.5天”计算费用时，必须说明起止时间、收费单位、半日计费依据、床位护理项目和计算公式。无法复核的折算金额不应直接作为犯罪数额。

### 退款与重复计算

建立四表交叉核对：

```text
控方涉案患者表
↔ 医保行政查实表
↔ 医院退款表
↔ 控方金额计算表
```

退款总额大于指控金额不当然证明没有损失；必须证明退款与涉案患者、项目、金额和时间相对应。

## 七、第五步：虚增耗材价格的独立审查

虚增耗材进价应单独建立链条：

```text
供应商关系
→ 采购谈判
→ 真实价格与虚增价格
→ 发票和财务凭证
→ 医保申报
→ 实际获利和分配
```

不认识供应商、未参与采购和付款、未掌握财务资料、没有价格沟通和分配证据的人员，不能仅因担任医保或管理职务而被概括归入虚增耗材骗保行为。

## 八、审查起诉阶段的三级请求

1. **证据不足不起诉**：挂床事实、病历伪造、共同故意或医保实际损失不能排除合理怀疑。
2. **酌定不起诉**：即使认定存在上传、审核或辅助行为，也应审查从犯、初犯、坦白、未获利、退赔和情节轻微。
3. **羁押必要性审查和取保**：两次退查后证据未实质补强、主要证据已固定、无现实社会危险性、可能判处较轻刑罚或缓刑。

## 九、进入 skill 的稳定规则

1. 医保骗保案件不得从“患者不在院”直接跳到“挂床住院”，必须先完成协议条款和患者事实逐项核对。
2. 不得从“上传病历”直接跳到“共同诈骗”，必须审查职权、信息、审核能力、明知、指使/帮助、获利和反向合规行为。
3. 结算单金额、违规申报金额和医保基金实际损失必须分开记录。
4. 行政处罚、基金追回、医院退款、审核扣减和年度清算必须与控方金额表逐笔比对。
5. 对医保负责人、名誉院长、医生、护士、财务和医院管理人员分别建立权力—信息—行为—获利矩阵。
6. 两次退查后的文书同时生成实体不起诉、酌定不起诉和羁押必要性审查三条路径。
