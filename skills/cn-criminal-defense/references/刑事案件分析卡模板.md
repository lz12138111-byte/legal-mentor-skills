- 文书功能：辩护/控告/检察监督/审查起诉意见/追赃挽损/强制措施/其他

## 二、案件一句话概括

用一两句话概括案件核心，不评价、不扩写。

## 三、文书任务识别

先判断这份刑事文书的真实任务，避免用错误框架分析。

| 文书任务 | 是否适用 | 说明 |
| --- | --- | --- |
| 辩护人视角 |  | 无罪、罪轻、量刑、程序辩护等 |
| 被害单位代理视角 |  | 控告、追诉遗漏、追赃挽损、监督侦查不作为等 |
| 被害人退赔损失核算 |  | 起诉书、判决或侦查结论低估被害人损失时，重构核价方法、补强证据并提出责令退赔金额 |
| 追诉遗漏犯罪事实报案 |  | 已有刑事案件基础上，补充报案遗漏事实、遗漏罪名、遗漏人员或犯罪单位 |
| 持续侵害制止 |  | 案件已立案或嫌疑人已被控制，但侵害仍持续，需要公安/检察采取涉案财物和现场控制措施 |
| 审查起诉意见 |  | 对起诉意见书事实、罪名、数额、人员提出意见 |
| 检察监督/侦查监督 |  | 要求纠正违法、不作为、遗漏追诉等 |
| 刑事立案监督/不应立案而立案 |  | 公安机关已经立案，但当事人认为案件不符合立案条件或事实基础已经变化，请求检察院监督撤案 |
| 刑民执行交叉拒执撤案申请 |  | 直接向公安申请撤销拒执案、解除网逃或强制措施，说明紧急避险、义务已履行、申请执行人撤销执行 |
| 刑民执行交叉拒执撤案共同意见 |  | 被立案人一方与申请执行人/被害单位一方形成共同撤案立场，直接向公安说明紧急避险、正当维权、义务已履行和不追究意见 |
| 被害单位诉讼权利保障申诉 |  | 公安/检察未送达文书、未告知案件移送、未提供维权相关资料，影响被害单位知情权、申请权和追赃挽损 |
| 公安依法履职督促 |  | 公安机关怠于撤案、解除措施、回应申请或履行法定职责时，向纪检监察/上级机关申请督促纠正 |
| 法院执行监督/终结执行督促 |  | 下级法院怠于终结执行、解除执行措施或长期不回复申请时，向上级法院申请执行监督 |
| 审查起诉阶段无罪证据调取/不起诉申请 |  | 已移送审查起诉，辩方认为存在无罪、罪轻或犯罪阻却事由，但关键证据未调取或需司法审计 |
| 审查起诉阶段实体不起诉法律意见 |  | 已具备一定事实和证据基础，向检察院完整提出无罪、不诉或犯罪阻却事由的实体论证 |
| 涉黑案件四特征拆解/去黑化 |  | 涉黑涉恶或多罪名团伙案件中，围绕组织特征、经济特征、行为特征、非法控制特征进行整体拆解 |
| 涉案财产审查监督 |  | 查封、扣押、冻结范围过宽，未区分违法所得、合法财产、公司财产、第三人财产、家属财产 |
| 强制措施 |  | 取保、不捕、羁押必要性审查等 |
| 一审罪轻辩护 |  | 在不主攻无罪时，围绕法定/酌定情节、证据评价和量刑目标进行庭审辩护 |
| 二审量刑上诉 |  | 攻击一审量刑情节认定、证据调取、法律适用和刑期目标 |
| 审查起诉阶段量刑意见 |  | 向检察机关提出罪轻、从宽、认罪认罚、量刑建议沟通意见 |
| 重大事项升级沟通/紧急报告 |  | 正式意见已提交但承办层面反馈不利时，向领导层提示重大事实、证据或量刑问题 |

如属于被害单位代理文书，必须额外分析：

- 被害单位权利结构
- 侦查机关或起诉意见书认定偏差
- 遗漏事实、遗漏罪名、遗漏人员
- 追赃挽损和涉案财物措施
- 持续侵害和程序监督请求

如属于被害人退赔损失核算文书，必须额外分析：

- 起诉书、判决或侦查结论对损失金额的原认定
- 被害人接受的无争议损失和争议损失
- 原核价方式的问题
- 替代核价方法及法律依据
- 替代核价方法所需的证据参数
- 是否需要法院、检察院调取关键证据
- 本金、利息、孳息、已付款扣除等金额结构
- 文书内部数值是否一致，是否需要律师复核

如属于追诉遗漏犯罪事实报案，必须额外分析：

- 既有刑事案件进展
- 遗漏事实分组
- 每组遗漏事实对应的嫌疑人、单位和拟评价罪名
- 每组事实的证据附件
- 与既有案件的关联性
- 追赃、查封、扣押、冻结请求
- 是否存在持续侵害或公共秩序风险

如属于持续侵害制止文书，必须额外分析：

- 已立案/羁押/查封冻结等司法介入现状
- 侵害为何仍在持续
- 持续侵害的具体路径
- 被害单位已采取的自救措施
- 仅靠自救为何不足
- 请求公安/检察采取的具体阻断措施
- 是否涉及公章证照、账户、合同、租户通知、现场控制或司法审计

如属于被害单位诉讼权利保障申诉文书，必须额外分析：

- 被害单位身份和刑事案件进展
- 被害单位或诉讼代理人已提出过何种具体申请
- 公安/检察未送达、未告知或未提供资料的表现
- 资料需求与被害单位维权、追赃挽损、经营接管的关系
- 申诉控告的法律依据和受理机关
- 请求事项是否限定为依法应送达、应告知、与维权相关的信息资料

如属于刑事立案监督/不应立案而立案文书，必须额外分析：

- 公安机关立案罪名和原始事实基础
- 申请人身份和申请检察监督的主体资格
- 原刑事立案基础为何不成立或为何已经发生重大变化
- 是否存在紧急避险、权利冲突、义务已履行、执行终结等正当理由
- 当事人是否已向公安申请撤案、解除措施或纠正
- 检察院受理“不应当立案而立案”的法律依据
- 请求事项是否明确为受理审查、监督撤案、纠正错误立案或解除相关措施

如属于刑民执行交叉拒执撤案申请文书，必须额外分析：

- 公安立案和网逃/强制措施状态
- 原生效判决、执行案和拒执立案基础
- 后续事实是否证明原执行基础存在真实利益冲突
- 未履行行为是否具有紧急避险、权利冲突或正当维权性质
- 执行义务是否已履行，申请执行人是否撤销执行或确认不追究
- 是否以情节显著轻微危害不大作为兜底
- 请求公安撤案、解除网逃或解除强制措施的具体事项

如属于刑民执行交叉拒执撤案共同意见文书，必须额外分析：

- 被立案人一方与申请执行人/被害单位一方是否共同出具意见
- 原执行义务和拒执案立案基础
- 继续履行原义务是否反而损害申请执行人/被害单位利益
- 未履行行为是否具有紧急避险、权利冲突或正当维权性质
- 执行义务是否已实际履行，执行目的是否已实现
- 申请执行人/被害单位是否确认不追究或请求撤案
- 请求公安撤案、解除网逃、解除强制措施的具体事项

如属于二审量刑上诉文书，必须额外分析：

- 一审判决核心认定
- 一审不采纳辩护意见的理由
- 二审攻击对象
- 法定/酌定量刑情节
- 主位与备位上诉理由
- 未调取证据或一审程序问题
- 量刑目标和刑期转化路径

如属于审查起诉阶段量刑意见，必须额外分析：

- 起诉意见书认定内容
- 辩方希望检察机关采纳的情节
- 认罪认罚、退赃退赔、配合调查等从宽基础
- 法定情节与酌定情节的组合方式
- 情理表达是否服务于量刑目标

如属于一审罪轻辩护词，必须额外分析：

- 起诉书指控与辩方是否接受定罪基础
- 庭审阶段需要法院采纳的法定情节
- 酌定情节的证据化程度
- 与认罪认罚具结书或检察量刑建议的关系
- 辩护观点在庭审中的表达顺序

如属于重大事项升级沟通/紧急报告，必须额外分析：

- 正式法律意见是否已提交
- 承办机关或承办人员反馈情况
- 需要升级沟通的重大问题
- 问题是否足以影响定罪、罪名、量刑或程序权利
- 沟通对象为何具备督促复核权限
- 文书语气是否克制、礼貌、聚焦、不过度施压

如属于公安依法履职督促文书，必须额外分析：

- 公安机关负有何种具体职责
- 当事人已提出何种申请
- 公安机关怠于履职的表现
- 原刑事案件或强制措施的事实基础是否已变化
- 是否存在民事、执行、公司治理等前置基础变化
- 请求纪检监察或上级机关督促的具体事项

如属于法院执行监督/终结执行督促文书，必须额外分析：

- 执行依据确定的义务
- 申请执行人是否撤销执行申请
- 被执行义务是否已履行或执行目的是否已实现
- 下级法院怠于终结执行或解除措施的表现
- 继续执行是否会造成不正义或权利损害
- 请求上级法院督办/执行监督的法律依据
- 需要解除的执行措施清单

如属于审查起诉阶段无罪证据调取/不起诉申请文书，必须额外分析：

- 移送审查起诉的罪名和时间
- 辩方主张的无罪、罪轻或犯罪阻却事实
- 该事实为什么影响罪与非罪、此罪与彼罪或起诉必要性
- 已提交的辩方证据编号和证明目的
- 需要检察院调取的证据对象、范围和线索
- 是否需要账户流水、公司账册、合同流、业务流、发票或司法审计
- 调证请求与不起诉结论之间的连接路径
- 是否需要退回补充侦查、自行补充侦查或组织听证

如属于审查起诉阶段实体不起诉法律意见文书，必须额外分析：

- 主位不起诉理由、补强不起诉理由和兜底从宽理由
- 控方形式行为与辩方实体评价之间的差异
- 是否存在紧急避险、正当防卫、正当维权、缺乏主观目的等阻却事由
- 阻却事由的事实要件是否逐项证据化
- 前置法依据是否可以支持行为正当性
- 不利事实是否通过用途限定、限度控制、未造成实害等方式处理
- 是否保留自首、坦白、认罪认罚、情节显著轻微等备用路径

如属于涉黑案件四特征拆解/去黑化文书，必须额外分析：

- 起诉意见书认定的组织者、领导者、积极参加者、一般参加者
- 下游犯罪是否代表组织意志、使用组织名义、维护组织利益
- 组织特征：成员、层级、规约、纪律、稳定性、控制属性
- 经济特征：收益来源、收益归属、统一管理、组织用途、是否豢养成员
- 行为特征：是否有组织多次实施违法犯罪，是否以暴力威胁为基本手段，是否为非作恶、欺压群众
- 非法控制特征：是否称霸一方，是否形成区域或行业控制，是否严重破坏经济社会秩序
- 是否存在债务纠纷、担保追偿、公司经营等事出有因或权利救济背景
- 是否存在将普通犯罪、个人犯罪、公司行为拔高为涉黑犯罪的风险
- 一退重移阶段哪些问题仍未补强

如属于涉案财产审查监督文书，必须额外分析：

- 查封、扣押、冻结财产清单
- 财产权利人、登记权利人、实际占有人
- 财产性质：违法所得、合法财产、本人财产、家属财产、公司财产、第三人财产
- 财产与案件事实的关联性
- 查扣措施对企业经营、第三方权益、员工工资、债务履行的影响
- 申请检察机关监督纠正的具体事项
