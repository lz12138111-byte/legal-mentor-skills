# 故意毁坏财物罪民刑切割与主观故意审查方法论

## 一、适用场景

适用于装修施工、相邻关系、拆除改造、物业管理、工程误操作等案件中，控方将财产损害、恢复费用或民事赔偿争议评价为故意毁坏财物罪的情形。

## 二、核心判断公式

```text
发生损坏
≠ 故意毁坏
≠ 对全部修复费用负责
≠ 对全部间接损失负责
≠ 达到刑事数额门槛
```

刑事审查应依次回答：

```text
损坏的是什么财物
→ 财物属于谁
→ 行为人何时知道、何时同意
→ 是否具有毁坏他人财物的故意
→ 损失是否由本次行为直接造成
→ 损失金额是否明确且达到入罪标准
→ 是否应由民事程序解决
```

## 三、第一层：民刑切割

不要只写“这是民事纠纷”。应当具体说明：

- 施工合同真实存在，施工目的具有合法性；
- 误拆、误操作、相邻影响属于施工风险或侵权过失；
- 恢复原状、修复费用、租金损失已有民事诉讼或可通过民事程序解决；
- 民事责任需要证明过错、因果关系和损失，但不等于刑法上的故意毁坏他人财物；
- 刑事程序不应被用来替代民事赔偿、推动超额索赔或解决责任分配争议。

可用结构：

```text
先承认可能存在民事责任
→ 再说明民事责任与刑事责任构成要件不同
→ 最后指出民事程序已有或仍可提供充分救济
```

## 四、第二层：行为对象审查

故意毁坏财物罪的行为对象是他人所有的公私财物。应制作对象清单：

| 对象 | 所有人 | 行为 | 是否进入犯罪评价 |
| --- | --- | --- | --- |
| 行为人自有房屋、设备 | 行为人本人 | 正常装修、改建、拆除 | 原则上不属于毁坏他人财物 |
| 相邻业主专有部分 | 他人 | 误拆、损坏、修复 | 需继续审查故意、损失和因果关系 |
| 共用墙、公共结构、共有部分 | 共有权人或业主共有 | 改造、影响结构 | 需明确财产权属和实际损坏对象 |
| 整体恢复、加固项目 | 未必是被损物本身 | 修复、升级或功能改善 | 不能当然作为犯罪损失 |

不要把“工程影响范围”“恢复方案范围”和“被毁财物范围”混为一谈。

## 五、第三层：用时间轴审查主观故意

至少分成三个节点：

1. 损坏发生前：行为人是否知道对象属于他人，是否有毁坏意图或放任心态。
2. 损坏发生时：行为人是否在场、指示、控制、参与或与施工人员形成共同故意。
3. 损坏发生后：行为人何时知情，是否反对、制止、修复、协商，或者仅因误判法律后果而同意后续处理。

需要特别防止：

- 用事后知道损害倒推事前故意；
- 用业主、发包人、法定代表人身份替代故意证明；
- 用同意拆除剩余部分倒推参与最初误拆；
- 用存在民事过错替代毁坏他人财物的刑事故意。

## 六、第四层：共同犯罪和施工责任

如果控方试图将施工人员的行为归责于业主，应审查：

| 审查项 | 关键问题 |
| --- | --- |
| 施工范围 | 合同、预算表是否包含涉案物体 |
| 指示关系 | 业主是否明确要求拆除他人财物 |
| 知情状态 | 施工前是否告知相邻物属于他人 |
| 现场控制 | 业主是否实际指挥、监督、选择具体操作 |
| 事后反应 | 知情后是否反对、制止或尝试修复 |
| 合同责任 | 施工方是否负有保护周边建筑的独立义务 |

发包人承担民事侵权责任或选任、监督责任，不等于当然与施工人员构成故意毁坏财物罪的共同犯罪。

## 七、第五层：损失和因果关系五层切割

### 1. 对象切割

只统计他人财物中实际受损部分，不把行为人自有财物、非涉案部分、升级改造部分计入。

### 2. 直接损坏切割

区分误拆飘檐、剩余钢筋、屋面功能、整体结构、室内装修和其他修复项目，逐项判断是否被本次行为直接损坏。

### 3. 鉴定事项切割

审查鉴定或报价是否超出委托范围。对整户恢复、整体加固、设计升级、功能改善的报价，不能直接替代被毁财物的价格或修复费用。

### 4. 因果关系切割

排查自然损耗、年久失修、原有瑕疵、第三人行为、后续施工和被害方自行扩大的损失。刑事定罪要求损失与涉案行为之间具有明确、直接、排他的证明基础。

### 5. 数额门槛切割

对剩余钢筋、局部构件等金额无法明确的部分，不能用整体工程报价补足。金额未查清或未达到立案标准时，应作为不起诉或存疑有利的核心理由。

## 八、证据组织方式

建议建立“行为—认知—对象—损失”四栏表：

| 事实问题 | 关键证据 | 控方证明缺口 | 辩方请求 |
| --- | --- | --- | --- |
| 误拆发生时是否知情 | 施工视频、微信群时间戳 | 不能证明甲方在场或事前知情 | 认定无事前故意 |
| 施工范围是什么 | 装修合同、预算表 | 合同未包含相邻飘檐 | 排除共同故意 |
| 同意拆剩余部分的性质 | 证人证言、聊天记录、物业意见 | 至多证明民事过错或错误判断 | 不作刑事故意评价 |
| 具体损坏是什么 | 现场照片、修复前后记录、鉴定 | 整体恢复不等于直接损坏 | 限定犯罪对象 |
| 损失金额多少 | 价格认定、报价、鉴定报告 | 委托事项超范围，金额相互矛盾 | 排除或降低证明力 |
| 是否有替代原因 | 房屋购买、使用、维护资料 | 毛坯、闲置、年久失修 | 否定排他因果关系 |

## 九、审查起诉阶段文书结构

```text
一、本案本质是普通民事侵权，刑事程序不应替代民事救济

二、故意毁坏财物罪的行为对象和犯罪损失范围应严格限定

三、行为人对初始损坏不知情，对后续行为至多存在民事过错，主观故意不足

四、现有鉴定、报价和损失证据不能证明直接损失、因果关系和数额门槛

五、通过修复、鉴定、协商和民事责任分配化解矛盾
```

主位请求是不起诉；备用论证可以写成：即使认为存在过错、同意或赔偿义务，也不能据此证明故意毁坏财物罪成立。

## 十、进入 skill 的稳定规则

1. 触发关键词包括：装修、误拆、相邻损害、拆除、恢复原状、工程报价、故意毁坏财物、民事侵权、刑事报案。
2. 先输出行为对象表，再输出时间轴和损失五层切割表。
3. 必须区分民事侵权责任、行政违法责任和故意毁坏财物罪刑事责任。
4. 业主、发包人、法定代表人身份不能替代共同故意和行为控制证明。
5. 对后续同意、默许或协商行为，必须单独评价，不能倒推初始误拆故意。
6. 工程整体恢复、加固、租金和功能损失，必须与实际被毁财物和直接因果关系逐项对应。
7. 鉴定、价格认定和报价均须审查委托事项、检材范围、方法、是否超范围以及是否把民事赔偿项目刑事化。
8. 不起诉意见的结尾除提出实体请求外，应提供修复、协商、鉴定和民事责任分配等可执行的矛盾化解方案。

## 十一、审判阶段的对象价值与鉴定关联性深化

进入一审阶段后，辩护重点可以从“民事侵权与刑事犯罪边界”进一步压缩到“被告人主观故意对应的具体对象和具体损失”。

审查顺序：

```text
主观故意何时产生
→ 该时点对应的客观行为是什么
→ 行为对象是否属于刑法意义上的财物
→ 财物是否仍具有经济或使用价值
→ 鉴定是否单独证明该对象的价值
→ 起诉数额能否由证据唯一推出
```

稳定规则：

- 被告人后形成的毁坏故意，不能当然覆盖此前由他人完成的损坏；但仍需审查共同犯罪、帮助行为和后续行为的独立责任。
- 技术性财物应沿“规格—毁损状态—可用性—价格”审查，不能仅凭原材料名称认定损失价值。
- 整体修复、房屋损失、检测、设计、监理、测绘、公证和诉讼支出不能自动并入故意毁坏财物罪犯罪金额。
- 多份鉴定意见不当然形成充分证明，必须逐项核对鉴定对象是否与起诉书指控行为一致、范围是否超出、因果关系是否直接、结论能否唯一推出涉案损失。
- 主位对象或数额争议与后位自首、认罪认罚、退赔应分层表达，不能以量刑表述削弱主位无罪或证据不足。
