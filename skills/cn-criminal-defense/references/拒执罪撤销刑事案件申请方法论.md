# 拒执罪撤销刑事案件申请方法论

## 一、用途

本文件用于沉淀老师在拒不执行判决、裁定罪案件中，直接向公安机关申请撤销刑事案件、解除网上追逃或其他刑事强制措施的方法。

该方法通常是拒执案纠错链条中的前端材料。若公安不处理、不回复，后续再转入公安履职督促、法院执行监督或检察立案监督。

## 二、基础工作流

```text
确认公安立案和强制措施状态
→ 还原原民事判决和执行义务
→ 识别执行义务背后的真实利益冲突
→ 证明未履行行为具有紧急避险、权利冲突或正当维权性质
→ 证明义务已履行或执行目的已实现
→ 证明申请执行人撤销执行或确认不追究
→ 请求公安撤案并解除网逃/强制措施
→ 附关键证据
```

## 三、核心审查清单

### 1. 案件状态

- 公安是否已经以拒执罪立案？
- 是否已经网上追逃、拘留、取保、监视居住或采取其他措施？
- 立案机关是派出所、分局还是经侦部门？

### 2. 原执行基础

- 原判决、裁定确定的义务是什么？
- 执行案号、申请执行人、被执行人分别是谁？
- 未履行行为发生在什么时间、什么背景下？

### 3. 正当化理由

- 是否存在正在发生的危险？
- 未履行是否为避免危险所不得已？
- 是否存在原控制人恶意诉讼、虚假交易、职务侵占、公司控制权争夺等背景？
- 未履行行为是否实际保护了申请执行人利益？

### 4. 撤案基础

- 义务是否已经履行？
- 是否有交接书、收条、印章交接证明等材料？
- 申请执行人是否撤销执行或申请终结执行？
- 申请执行人是否明确不追究？

## 四、文书结构

```text
一、申请事项：撤案、解除网逃或强制措施
二、原民事判决、执行案和拒执立案背景
三、后续刑事案件或新事实证明原执行基础存在问题
四、未履行行为具有紧急避险或正当维权性质
五、义务已履行，申请执行人已撤销执行或不再追究
六、情节显著轻微危害不大或继续追诉无现实必要
七、具体请求和附件
```

## 五、表达规则

1. 请求事项必须具体写明撤销刑事案件、解除网逃、解除刑事强制措施。
2. 可以先承认形式上“不当”，再说明为何不应犯罪化，降低对抗性。
3. 紧急避险不能只写结论，要写危险来源、保护利益、避险行为、避免结果。
4. “法不强人所难”“实质正义”等表达要有事实支撑。
5. 附件应优先放交接书、撤销强制执行申请书、刑事立案/批捕材料、股东会决议等。

## 六、与相邻文书关系

```text
撤销刑事案件申请：直接找公安主动撤案。
共同法律意见：由被立案人一方和申请执行人/被害单位一方共同强化撤案立场。
公安履职督促：公安收到撤案申请后不处理、不回复时使用。
法院执行监督：执行程序仍不终结时使用。
刑事立案监督：公安仍坚持立案时，请检察院监督不应立案而立案。
```

## 七、进入 Skill 的规则

当用户输入“撤销拒执案”“解除网逃”“公章已交但公安不撤案”“拒不执行判决裁定罪撤案申请”“申请执行人已撤销执行”等情形时，skill 应进入本工作流。
